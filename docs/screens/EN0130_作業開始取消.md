# 作業開始取消 / 処理開始取消 (EN0130)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0130 |
| ルート | `/cancel-work-start` |
| ページタイトル | SPIRYTUS - 作業開始取消/処理開始取消 (EN0130) |
| 使用サービス | WorkService |

## 概要

作業開始または処理開始を取り消す画面。ロットの現在状態（NowSt）に応じて、「作業開始取消」と「処理開始取消」を自動判定する。

## 画面構成

### 1. キャリアID入力エリア
- 他画面と同一仕様

### 2. 取消モードバナー（照合後に表示）
- 黄色の警告アラートで「処理開始取消」または「作業開始取消」を表示
- 現在のロット状態を併記

### 3. ロット情報カード
- 他画面と同一レイアウト

### 4. 取消設定カード
| 入力項目 | 説明 |
|---------|------|
| 戻す先 | ドロップダウン: 「作業待ち」(0) / 「前処理」(1)。処理中の場合のみ「前処理」が選択可能 |
| 作業メモ | 最大2048文字、3行テキスト |

### 5. ボタンエリア
- **確定**: 黄色（警告色）
- **クリア**

## モード判定ロジック

| ロット状態 (NowSt) | 取消モード | 「前処理に戻す」 |
|-------------------|-----------|----------------|
| 「処理中」 | 処理開始取消 | 選択可能 |
| その他 | 作業開始取消 | 選択不可 |

## API通信

| メッセージID | 用途 | ClassDivision |
|-------------|------|---------------|
| `lot_.curstate` | ロット現在状態取得 | 19 |
| `lot_.cnclwrkstart` | 作業開始取消実行 | - |
