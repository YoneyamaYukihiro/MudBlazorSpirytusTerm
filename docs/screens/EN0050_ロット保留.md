# ロット保留 / ロット保留解除 (EN0050 / EN00A0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0050 (保留) / EN00A0 (保留解除) |
| ルート | `/lot-hold` |
| ページタイトル | SPIRYTUS - ロット保留/保留解除 (EN0050/EN00A0) |
| 使用サービス | LotHoldService, WorkService |

## 概要

ロットの保留登録と保留解除を行う画面。モード切替で「保留」「保留解除」を切り替える。

## 画面構成

### 1. モード切替 + キャリアID入力エリア
- **トグルグループ**: 「保留」/「保留解除」切替
- キャリアID入力欄（6桁）
- 照合ボタン

### 2. ロット情報カード
- 他画面と同一レイアウト

### 3. 操作フォーム（モード別）

#### 保留モード
| 入力項目 | 説明 |
|---------|------|
| 保留理由 * | ドロップダウン（MasReasonCode から取得） |
| 保留期限日 | YYYYMMDD 形式、8桁テキスト |
| 保留コメント | 最大256文字、3行テキスト |

#### 保留解除モード
- 保留情報テーブル（理由・保留日時・担当者・期限）
- 保留がない場合は「このロットに保留はありません」アラート
- 解除コメント入力（最大256文字）

### 4. ボタンエリア
- **確定**: 保留モードは黄色、解除モードは緑色。アイコンも変化（ロック/ロック解除）
- **クリア**

## 操作フロー

### 保留
1. 「保留」モードを選択
2. キャリアID入力 → 照合（ClassDivision: "14"）
3. 保留理由を選択（必須）
4. 確定で保留登録

### 保留解除
1. 「保留解除」モードを選択
2. キャリアID入力 → 照合（ClassDivision: "15"）
3. 保留情報テーブルから対象を選択
4. 確定で保留解除

## 初期化処理

- 画面表示時に `LotHoldService.GetHoldReasonsAsync()` で保留理由マスタを取得

## API通信

| メッセージID | 用途 |
|-------------|------|
| `mas_.reasoncode` | 保留理由マスタ取得 |
| `lot_.curstate` | ロット現在状態取得 |
| `lot_.holdinfo` | 保留情報取得（解除モード時） |
| `lot_.hold____` | 保留登録 |
| `lot_.releasehold` | 保留解除 |
