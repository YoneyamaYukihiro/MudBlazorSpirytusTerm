# EN02O0 時間制限流動設定

## 概要

時間制限流動の設定を確認・変更する画面。制限タイプを選択し、フロー制限と装置ごとの制限を編集する。

VBソース: `VB/02O0/CtsfrmxxEN02O0.vb`, `VB/02O0/CtsbasxxMG02O0.vb`

---

## 画面要素

### 制限タイプ選択

| 値 | 説明 |
|----|------|
| 1 | 開始/終了2工程(時間制限：以内)、後装置：処理部レシピあり |
| 2 | 開始/終了2工程(時間制限：以内)、後装置：バッチ装置 |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 最新取得 | 選択した制限タイプの設定情報を `time.restrictstatus` で取得 |
| 確定 | 変更行（EDIT_FLAG="1"）のみ `time.restrictregist` で送信 |

### フロー設定グリッド（RESTRICT_FLOW_LIST）

| 列 | 説明 |
|----|------|
| No | 行番号 |
| ロット保留 | LOT_STOP_ON（編集可: 手動=0, 自動=1） |
| 大工程(FROM) | FROM_OP_ID（読み取り専用） |
| 小工程(FROM) | FROM_STEP_ID（読み取り専用） |
| 大工程(TO) | TO_OP_ID（読み取り専用） |
| 小工程(TO) | TO_STEP_ID（読み取り専用） |
| 最終更新日時 | EDIT_TIME（読み取り専用） |
| 最終更新者 | EDIT_EMP_NAME（読み取り専用） |

### 装置設定グリッド（RESTRICT_WP_LIST）

| 列 | 説明 |
|----|------|
| No | 行番号 |
| 装置名 | WP_NAME（読み取り専用） |
| 処理部 | PROCESSING_NAME（読み取り専用） |
| ロット保留解除 | LOT_STOP_OFF（タイプ1: 手動=0/自動=1 選択可, タイプ2: "バッチ編成設定に従う" 固定表示） |
| 時間制限 在庫数/作業待数 | WAIT_LOT_NUM（タイプ1: 1〜9 編集可, タイプ2: "装置最大処理数に従う" 固定表示） |
| 最終更新日時 | EDIT_TIME（読み取り専用） |
| 最終更新者 | EDIT_EMP_NAME（読み取り専用） |

---

## タイプ2（バッチ装置）の特殊表示

VBソース: `CMstrLotStopOffFoBatch = "バッチ編成設定に従う"`, `CMstrWaitLotNumFoBatch = "装置最大処理数に従う"`

制限タイプ2のとき、装置グリッドの `LOT_STOP_OFF` 列と `WAIT_LOT_NUM` 列はサーバー値に関わらず固定テキストで表示される。送信時もこれらの列は通常どおり現在値をそのまま送る。

---

## 確定の仕組み

1. フロー行または装置行の編集可能フィールドを変更すると、その行の `IsEdited` フラグが立つ
2. 「確定」押下で全行を送信するが、変更行のみ `EDIT_FLAG="1"`、未変更行は `EDIT_FLAG="0"` を付与
3. サーバー側で `EDIT_FLAG="1"` の行だけ更新処理される
4. 成功後、同じ制限タイプで `time.restrictstatus` を再呼び出しして画面を更新

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `time.restrictstatus` | 01.00 | 時間制限流動設定情報取得 |
| `time.restrictregist` | 01.00 | 時間制限流動設定変更 |
