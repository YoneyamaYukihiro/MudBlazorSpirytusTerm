# キャリア管理 (EN00G0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00G0 |
| ルート | `/carrier-management` |
| ページタイトル | SPIRYTUS - キャリア管理 (EN00G0) |
| 使用サービス | CarrierService |

## 概要

キャリアの一覧表示・検索と、選択したキャリアの手動出庫を行う画面。

## 画面構成

### 1. 検索エリア
| 入力項目 | 説明 |
|---------|------|
| キャリアID | 任意入力（6桁、大文字自動変換）。空欄で全件検索 |
| 検索ボタン | |
| クリアボタン | |
| 件数表示 | |

### 2. キャリア一覧グリッド（MudDataGrid）
| カラム | ソート | フィルタ | 説明 |
|--------|-------|---------|------|
| キャリアID | ○ | ○ | CarrierId |
| 空/実 | ○ | × | EmptyFlag: "1"→空, それ以外→実 |
| 状態 | ○ | ○ | CarrierStatId |
| 使用開始日時 | ○ | ○ | StartTime |
| クリーン | ○ | × | CleanFlag: "1"→済, それ以外→未 |
| クリーン日時 | ○ | ○ | CleanTime |
| 総使用回数 | ○ | ○ | TotalUseCount |
| クリーン回数 | ○ | ○ | CleanCount |
| クリーン後使用 | ○ | ○ | AfterCleanUseCount |

- 行選択可能（単一選択）
- 仮想スクロール対応
- 空キャリア行: 背景色 #E3F2FD（水色）

### 3. 手動出庫エリア（キャリア選択時に表示）
| 入力項目 | 必須 | 最大長 | 説明 |
|---------|------|--------|------|
| ストッカーID | ○ | 20 | 出庫先ストッカー |
| 作業者ID | ○ | 10 | 操作者 |
| 手動出庫ボタン | | | 黄色（警告色） |

## 操作フロー

1. キャリアID入力（任意）→ 検索
2. 一覧からキャリアを選択
3. ストッカーIDと作業者IDを入力
4. 手動出庫ボタンで出庫実行
5. 成功時: Snackbar表示、選択解除、一覧再取得

## API通信

| メッセージID | 用途 | MsgVer |
|-------------|------|--------|
| `carr.list____` | キャリア一覧取得 | 03.00 |
| `carr.manuoutport` | キャリア手動出庫 | 01.00 |
