# EN0110 装置状態変更

## 基本情報

| 項目 | 値 |
|------|----|
| 機能ID | EN0110 |
| ルート | `/equipment-status-change` |
| ページタイトル | SPIRYTUS - 装置状態変更 (EN0110) |
| 使用サービス | `EquipmentService`, `EquipmentModeService` |

VBソース: `VB/0110/CtsfrmxxEN0110.vb`

---

## 概要

装置グループと装置を選択して現在の装置状態を取得し、変更後の装置状態を選択して確定する画面。EN00C0（タブ2）と同等の機能を単独画面として提供する。装置状態マスタ一覧テーブルから行クリックで状態を選択することもできる。

---

## 画面構成

### 装置グループ・装置選択エリア

| フィールド | 説明 |
|-----------|------|
| 装置グループ | `mas_.mcgrouplist` から取得したグループ一覧 |
| 装置 | 選択グループに紐づく装置一覧（`eq__.areacurlist` から取得） |
| 装置状態取得ボタン | 選択装置の現在状態を `eq__.state___` で取得 |

### 現在の装置状態表示エリア

| 項目 | タグ |
|------|------|
| 装置ID | WP_ID |
| 装置名 | WP_NAME |
| 現在状態 | USE_NAME（状態IDに応じた色チップで表示） |
| 状態ID | USE_ID |
| 運用モード | MES_MODE_ID |
| 稼動状態 | WP_STOP_FLAG（"1"=停止中、それ以外=通常） |

状態IDの色コード:

| 状態ID | 色 | 意味 |
|--------|-----|------|
| 10 | 緑（Success） | 通常・量産 |
| 20 | 黄（Warning） | 試験・評価 |
| 30 | 赤（Error） | 異常 |
| 40 | 青（Info） | 保守・PM |
| 50 | グレー（Secondary） | 停止 |

### 装置状態変更フォーム

| フィールド | 説明 |
|-----------|------|
| 変更後装置状態 | `mas_.wpuselist` から取得した状態マスタ一覧（必須） |
| メッセージ | `eq__.wpmsglist` から取得した装置メッセージ一覧（任意、状態選択後に表示） |
| 社員ID | 操作者ID（必須）。Enterキーで確定も可 |
| コメント | 任意テキスト |

変更内容プレビュー: 変更後装置状態選択時に、現在の状態チップ → 変更後の状態チップをインラインで表示する。

| ボタン | 説明 |
|--------|------|
| 確定 | `eq__.chguse__` で装置状態変更 |
| クリア | 入力フォームをクリア |

### 装置状態マスタ一覧テーブル

装置状態マスタ取得後に表示。行クリックで変更後装置状態として選択できる。

| 列 | タグ |
|----|------|
| 状態ID | USE_ID |
| 状態名 | USE_NAME（色チップ表示） |
| 通常 | NORMAL_STATE_FLAG（"1"なら "○"） |
| 停止 | USE_STOP_FLAG（"1"なら "停止"） |
| メッセージ | MESSAGE_TEXT |

---

## 操作フロー

1. 装置グループを選択 → 装置リストが自動更新される
2. 装置を選択 → `eq__.wpmsglist` でメッセージリストを更新、フォームをクリア
3. 「装置状態取得」をクリック → `eq__.state___` で現在状態を取得
4. 変更後装置状態を選択（フォームまたはマスタテーブル行クリック） → `eq__.wpmsglist` を再取得
5. 必要に応じてメッセージを選択し、社員IDを入力
6. 「確定」をクリック（または社員IDフィールドでEnterキー）
7. `eq__.chguse__` を実行
8. 成功時：スナックバー表示、装置状態を再取得してフォームをクリア

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `mas_.mcgrouplist` | 01.00 | 装置グループ一覧取得 |
| `eq__.areacurlist` | 02.00 | 装置グループ内装置一覧取得 |
| `eq__.state___` | 03.00 | 装置現在状態取得（VBソース: cmdSearch_Click → eq__.state___） |
| `mas_.wpuselist` | 03.00 | 装置状態マスタ取得 |
| `eq__.wpmsglist` | 01.00 | 装置状態メッセージ取得（VBソース: cmbUseName_Validate → prvblnWpMsg_Disp） |
| `eq__.chguse__` | 05.00 | 装置状態変更（VBソース: cmdExecution_Click → pubblnEqChguse_Ins） |
