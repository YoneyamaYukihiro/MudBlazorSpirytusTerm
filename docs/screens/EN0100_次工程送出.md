# 次工程送出 (EN0100)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0100 |
| ルート | `/next-send` |
| ページタイトル | SPIRYTUS - 次工程送出 (EN0100) |
| 使用サービス | WorkService |

## 概要

キャリアIDからロットを照合し、次工程情報を確認した上でロットを次工程へ送出する画面。

## 画面構成

### 1. キャリアID入力エリア
- 他画面と同一仕様

### 2. ロット情報カード
- 他画面と同一レイアウト

### 3. 次工程一覧テーブル（読み取り専用）
| カラム | 説明 |
|--------|------|
| 大工程 | NextOpId |
| 小工程 | NextStepId |
| D | StepDivision="1"の場合「○」 |
| 装置 | WpName をカンマ区切りで表示 |

- MudSimpleTableで表示（選択不可、情報参照のみ）

### 4. 追加入力エリア
| 入力項目 | 最大長 |
|---------|--------|
| 作業メモ | 128 |

### 5. ボタンエリア + ガイダンスメッセージ

## 操作フロー

1. キャリアID入力 → 照合
2. 照合時に `lot_.curstate` と `lot_.nextsteplist` を順に呼び出し
3. 次工程一覧を確認
4. 確定で送出実行
5. 成功時: Comments があればガイダンスとして表示

## API通信

| メッセージID | 用途 | MsgVer |
|-------------|------|--------|
| `lot_.curstate` | ロット現在状態取得 | 04.00 |
| `lot_.nextsteplist` | 次工程一覧取得 | - |
| `lot_.nextsend` | 次工程送出実行 | - |
