# EN00M0 バッチ管理

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00M0 |
| ルート | `/batch-lot-management` |
| ページタイトル | SPIRYTUS - バッチ管理 (EN00M0) |
| 使用サービス | `BatchLotService` |

## 概要

装置グループを選択して在庫ロット一覧（製品ロット / モニタロット）を取得し、バッチの新規登録・変更・削除を行う画面。ロット一覧のチェックボックスで対象ロットを選択し、装置・レシピIDを指定してバッチ操作を実行する。

VBソース: `VB/00M0/CtsfrmxxEN00M0.vb`, `VB/00M0/CtsbasxxMG00M0.vb`

---

## 画面構成

### 装置グループ・最新取得エリア

| フィールド | 説明 |
|-----------|------|
| 装置グループ | `mas_.mcgrouplist` (CLASS_DIVISION="2G") で取得した一覧をドロップダウン表示。変更時に装置一覧を再取得 |
| 最新取得ボタン | 選択中の装置グループの在庫ロット一覧を取得。製品ロット (CLASS_DIVISION="2T") とモニタロット (CLASS_DIVISION="2Z") を並列取得 |

### 在庫ロット一覧（最新取得後に表示）

製品ロット・モニタロットの2タブで構成される。各タブの列は共通。

| 列 | タグ | 説明 |
|----|------|------|
| (チェック) | — | バッチ操作対象ロットを選択するチェックボックス |
| № | — | 行番号 |
| キャリアID | CARRIER_ID | — |
| ロットID | LOT_ID | — |
| 種 | FLOW_CLASS | フロー区分 |
| 優 | LOT_PRIORITY | 優先度 |
| WF | WF_QUANTITY | WF枚数 |
| レシピ | RECIPE_ID | — |
| 時間制限 | LIMIT_TIME | — |
| 作業条件 | OPTION_TEXT | — |
| 大工程 | OP_ID | — |
| 小工程 | STEP_ID | — |
| 蒸着バッチID | J_BATCH_ID | EQ_TYPE="19" 系バッチID |
| 表面処理バッチID | H_BATCH_ID | EQ_TYPE="20" 系バッチID |

### バッチ操作エリア（最新取得後に表示）

#### 操作パラメータ

| フィールド | 説明 |
|-----------|------|
| 装置 | `mas_.wplist__` (CLASS_DIVISION="20") で取得した装置一覧。装置グループ選択後に自動ロード |
| レシピID | 最大32文字 |
| バッチID（変更・削除時） | 変更または削除するバッチのID。最大32文字 |

#### 選択ロット一覧

ロット一覧でチェックを入れたロットが表示される（順、キャリアID、ロットID、種、WF、レシピ）。削除ボタンで個別に選択を解除できる。

#### 操作ボタン

| ボタン | CLASS_DIVISION | 条件 | 説明 |
|--------|---------------|------|------|
| 新規登録 | `""` (空文字) | 選択ロット1件以上 + 装置選択 | バッチを新規作成 |
| 変更 | `"06"` | 選択ロット1件以上 + 装置選択 + バッチID入力 | 既存バッチを変更 |
| 削除 | `"05"` | バッチID入力 | 既存バッチを削除 (ロット選択不要) |
| クリア | — | — | 選択ロット・レシピID・バッチIDをリセット |

## 操作フロー

1. 画面初期表示時に `mas_.mcgrouplist` (MsgVer="01.00", CLASS_DIVISION="2G") で装置グループ一覧を取得
2. 装置グループを選択 → `mas_.wplist__` (MsgVer="05.01", CLASS_DIVISION="20") で装置一覧を取得
3. 「最新取得」ボタン押下
   - `lot_.mcgplotlist` (MsgVer="04.00", CLASS_DIVISION="2T") で製品ロット一覧を取得
   - `lot_.mcgplotlist` (MsgVer="04.00", CLASS_DIVISION="2Z") でモニタロット一覧を取得（並列実行）
   - 失敗時: エラーアラートを表示
   - 成功時: 製品ロット / モニタロットタブに結果を表示
4. ロット一覧のチェックボックスで操作対象ロットを選択
5. 装置・レシピID・バッチID（必要時）を入力し、操作ボタンを押下
   - 「新規登録」: `bat_.change__` (MsgVer="03.00", CLASS_DIVISION="") で新規バッチ作成
   - 「変更」: `bat_.change__` (MsgVer="03.00", CLASS_DIVISION="06") でバッチ変更
   - 「削除」: `bat_.change__` (MsgVer="03.00", CLASS_DIVISION="05") でバッチ削除
6. バッチ操作成功後、在庫ロット一覧を自動再取得

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `mas_.mcgrouplist` | 01.00 | 装置グループ一覧取得 (CLASS_DIVISION="2G") |
| `mas_.wplist__` | 05.01 | 装置一覧取得 (CLASS_DIVISION="20") |
| `lot_.mcgplotlist` | 04.00 | 在庫ロット一覧取得 (CLASS_DIVISION="2T" または "2Z") |
| `bat_.change__` | 03.00 | バッチ新規登録 / 変更 / 削除 (CLASS_DIVISION="" / "06" / "05") |
