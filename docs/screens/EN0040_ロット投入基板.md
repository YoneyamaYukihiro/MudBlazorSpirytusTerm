# EN0040 ロット投入(基板)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0040 |
| ルート | `/lot-throwin-substrate` |
| ページタイトル | SPIRYTUS - ロット投入(基板) (EN0040) |
| 使用サービス | `LotThrowinSubstrateService` |

## 概要

キャリアIDを入力してキャリア状態を照合し、基板ロットを工程へ投入する画面。照合後にロット情報・スロットマップ・投入設定を表示し、「投入確定」ボタンで投入を実行する。

VBソース: `VB/0040/CtsbasxxMG0040.vb`

---

## 画面構成

### キャリアID入力エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID | 最大6文字。大文字変換。Enterキーまたは「照合」ボタンで照合 |
| 照合ボタン | `carr.curstate` (CLASS_DIVISION="26") でキャリア状態を取得 |

### ロット情報カード（照合後に表示）

| 項目 | タグ |
|------|------|
| ロットID | LOT_ID |
| 機種ID | PD_ID + PD_NAME |
| ロット状態 | NOW_ST |
| ロット担当者 | ENG_EMP_NAME |
| WF枚数 | WF_NUM |
| スロットサイズ | SLOT_SIZE |

### 投入設定カード（照合後に表示）

| フィールド | 説明 |
|-----------|------|
| 優先度 | `mas_.priolist` から取得した一覧をドロップダウン表示。初期値は先頭項目 |
| 投入装置 | `mas_.wplist__` から取得した装置一覧をドロップダウン表示 |
| 処理形態 | 「オンライン」(1) / 「オフライン」(0) |
| 作業者ID | 最大10文字 |

### スロットマップ（照合後に表示）

スロットサイズ分の行を生成する。

| 列 | 説明 |
|----|------|
| スロット | スロット位置 (01, 02, ...) |
| 在庫ロットID | 各スロットに載るWFの在庫ロットIDを入力。最大20文字 |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 投入確定 | スロットマップと投入設定を `lot_.throwin_` へ送信 |
| クリア | 全フィールドをリセットし初期状態に戻す |

---

## 操作フロー

1. キャリアIDを入力してEnterキーまたは「照合」ボタンを押下
2. `carr.curstate` (MsgVer="05.02", CLASS_DIVISION="26") でキャリア状態を取得
   - 失敗時: エラーアラートを表示
   - 成功時: ロット情報カード・投入設定カード・スロットマップを表示
3. 必要に応じてスロットマップに在庫ロットIDを入力
4. 優先度・投入装置・処理形態・作業者IDを設定
5. 「投入確定」ボタン押下 → `lot_.throwin_` (MsgVer="04.00") で投入実行
   - 失敗時: エラーアラートを表示
   - 成功時: ガイダンスメッセージを表示し画面をクリア

---

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `carr.curstate` | 05.02 | キャリア状態照合 (CLASS_DIVISION="26") |
| `mas_.priolist` | 01.00 | 優先度一覧取得 |
| `mas_.wplist__` | 05.01 | 投入装置一覧取得 |
| `lot_.throwin_` | 04.00 | ロット投入(基板)実行 |
