# EN0120 ロット編成(保留/払出WF)

## 基本情報

| 項目 | 値 |
|------|----|
| 機能ID | EN0120 |
| ルート | `/lot-composition` |
| ページタイトル | SPIRYTUS - ロット編成(保留/払出WF) (EN0120) |
| 使用サービス | `LotCompositionService` |

VBソース: `VB/0120/CtsbasxxMG0120.vb`

---

## 概要

キャリアIDを入力してロットを照合し、WFのスロットマップを確認した上で在庫ロット投入（ロット編成）を実行する画面。保留・払出状態のウェーハを対象とした WF の投入処理を行う。優先度を指定して編成確定を送信する。

---

## 画面構成

### キャリアID入力エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID | 最大6文字（大文字変換）。Enterキーまたは「照合」ボタンで照合を実行 |
| 照合ボタン | `carr.curstate`（MsgVer="05.02", CLASS_DIVISION="26"）でキャリア状態を取得 |

### ロット情報カード（照合後に表示）

| 項目 | タグ |
|------|------|
| ロットID | LOT_ID |
| 機種 | PD_ID（PD_NAME） |
| ロット状態 | NOW_ST |
| ロット担当者 | ENG_EMP_NAME |
| WF枚数 | WF_NUM |

### 編成設定カード（照合後に表示）

| フィールド | 説明 |
|-----------|------|
| 優先度 | `mas_.priolist`（MsgVer="01.00"）から取得した優先度一覧から選択。初期値は先頭要素 |
| 作業者ID | 作業者の社員ID（任意） |

### スロットマップ（照合後に表示）

キャリアの WF 枚数（最大25スロット）に応じて行を生成するテーブル。

| 列 | 説明 |
|----|------|
| スロット | スロット番号（ゼロ埋め2桁） |
| WFID | ウェーハID |
| 状態 | WF状態（WF_STAT） |
| GRB | GRB区分 |
| 元ロットID | BEFOR_LOT_ID |
| 選択 | チェックボックス（編成対象WFの選択） |

### ガイダンスメッセージ

編成確定後に成功応答の `MSG` と `MSG_CODE` をインラインアラート（Info）で表示。

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 編成確定 | `inv_.throwin_`（MsgVer="03.00"）を呼び出してロット編成を実行 |
| クリア | 全入力・表示内容をリセット |

---

## 操作フロー

1. キャリアIDを入力（6文字）してEnterキーまたは「照合」ボタンを押下
2. `carr.curstate` でキャリア状態取得 → ロット情報カードとスロットマップが表示される
3. 優先度と作業者IDを設定
4. スロットマップで編成対象のWFを確認（必要に応じてチェックボックスで選択）
5. 「編成確定」ボタンを押下
6. `inv_.throwin_` を実行
7. 成功後：スナックバー表示、ガイダンスメッセージを表示し、フォームをクリア

---

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `carr.curstate` | 05.02 | キャリア状態取得（CLASS_DIVISION="26"） |
| `mas_.priolist` | 01.00 | 優先度一覧取得 |
| `inv_.throwin_` | 03.00 | 在庫ロット投入（ロット編成実行）（VBソース: pubblnInvThrowin_Sel） |
