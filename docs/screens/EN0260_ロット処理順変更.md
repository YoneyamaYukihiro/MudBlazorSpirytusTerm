# EN0260 ロット処理順変更

## 概要

装置の待ちロットキューに対して、処理順番号を割り当て・変更・解除する画面。

VBソース: `VB/COMN/CtsfrmxxCM0110.vb`

---

## 画面要素

### 検索エリア

| 項目 | 説明 |
|------|------|
| 装置グループ | `mas_.mcgrouplist` で取得した装置グループ一覧から選択 |
| 装置名 | `eq__.areacurlist` で取得した装置一覧から選択 |
| 最新取得ボタン | ロット待ちリストを取得する |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 1つ前に戻る | 最後に採番した変更後処理順№をクリアする |
| 処理順全解除 | 全ての変更後処理順№をクリアし、空リストで確定する |
| 確定 | 変更後処理順番号が設定されたロットを送信する |

### ロット一覧グリッド

| 列 | 説明 |
|----|------|
| No | 初期取得順番号 |
| 保/停 | 保留(保)・停止(停)・リワーク(リ)・追加流動(追) |
| 現処理順 | 現在の処理順№（"999" は "標準" と表示） |
| 変更後処理順 | ユーザーが割り当てた処理順№（001〜998） |
| 時間制限 | 時間制限情報 |
| 進捗度 | ロット進捗度 (1A0 基板工程のみ意味あり) |
| ロットID | ロットID |
| GRB区分 | GRB区分 |
| 種別 | 流動区分 |
| 優先順位 | ロット優先順位 |
| 大工程 | 大工程ID |
| 小工程 | 小工程ID |
| レシピ | レシピID |
| 処理開始予実 | 処理開始予定/実績日時 |
| ロット担当 | 担当者名 |
| 状態 | 現在状態 |
| WF枚数 | ウェーハ枚数 |
| チップ | チップ数 |
| 現在位置 | 搬送中の場合は "→ 搬送先" を表示 |
| 最終更新日時 | ロット最終更新日時 |
| リワーク | リワーク(リ) / 追加流動(追) |
| コメント | コメントありの場合アイコン表示 |
| キャリアID | キャリアID |

---

## 処理順採番の仕組み

1. 行をクリックすると変更後処理順に次の番号が割り当てられる（001, 002, 003 …）
   - 処理可能レシピフラグ (`AVAILABLE_RECIPE_FLAG`) が "1"（処理限定）の行は採番不可
   - 998 まで採番可能
2. 「1つ前に戻る」で直前の採番を取り消す
3. 「確定」で `lot_.chgseqnum` を送信して処理順を変更する

---

## 行の背景色

| 条件 | 色 |
|------|----|
| 変更後処理順が設定済み | 水色 (#bbdefb) |
| 保留または停止 | 黄色 (#FFFF99) |
| 処理限定レシピ (AvailableRecipeFlag=1) | グレー (#cccccc) |
| FRレシピ不可 (FrRecipeFlag=1) | ライトグリーン (#c8f0c8) |
| ダミーロット (FD/SD/ED) | オレンジ (#FFA500) |

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `mas_.mcgrouplist` | 01.00 | 装置グループ一覧取得 |
| `eq__.areacurlist` | 02.00 | 装置一覧取得 |
| `lot_.list____` | 12.01 | ロット待ちリスト取得 (CLASS_DIVISION="25") |
| `lot_.chgseqnum` | 06.00 | ロット処理順変更 |
