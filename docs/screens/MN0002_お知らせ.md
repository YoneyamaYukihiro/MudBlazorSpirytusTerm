# お知らせ (MN0002)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | MN0002 |
| ルート | `/` |
| ページタイトル | SPIRYTUS - お知らせ |
| 使用サービス | MenuService |

## 概要

アプリケーションのホーム画面。システムからの「お知らせ」を表示する。

## 画面構成

### ヘッダー
- 「お知らせ」タイトル
- 再取得ボタン（リフレッシュアイコン）

### お知らせ本文エリア
- ローディング中: スケルトン表示（3行）
- 取得失敗時: 警告アラート
- お知らせなし: 「お知らせはありません。」テキスト
- 正常時: テキスト本文（改行保持、折り返しあり）

## 操作フロー

1. 画面初期表示時に `MenuService.GetInformationAsync()` を自動呼び出し
2. お知らせテキストを表示
3. ユーザーはリフレッシュボタンで再取得可能

## API通信

| メッセージID | 用途 |
|-------------|------|
| `util.information` | お知らせテキスト取得 |
