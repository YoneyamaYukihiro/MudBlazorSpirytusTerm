# 装置別ロット一覧 (EN0150)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0150 / EN0151 (防湿ALD) |
| ルート | `/lot-list` |
| ページタイトル | SPIRYTUS - 装置別ロット一覧 (EN0150) |
| 使用サービス | LotListService, EquipmentService |

## 概要

装置グループ・装置を選択し、その装置に紐づくロット一覧を表示する画面。基板系(1A0)と組立系(2A0)で表示カラムが異なる。

## 画面構成

### 1. 検索エリア
| 入力項目 | 説明 |
|---------|------|
| 装置グループ | ドロップダウン（初期化時に自動読込） |
| 装置 | ドロップダウン（グループ選択時に読込） |
| 最新取得ボタン | ロット一覧と装置状態を並列取得 |

### 2. ステータスライン（取得成功時）
- 取得日時
- 件数
- 装置状態名 (UseName)
- MESモードID (MesModeId)
- 装置ステータス名 (WpStatusName)
- 集約ルール (CollectTypeFlag)

### 3. 色凡例
| 色 | 意味 |
|----|------|
| 黄色 (#FFFF99) | 保留 / 停止 |
| グレー (#D3D3D3) | レシピ制限 |
| 緑色 (#90EE90) | FRレシピ不可 |
| オレンジ (#FFA500) | ダミーロット |

### 4. データグリッド（MudDataGrid）
#### 共通カラム
| カラム | 説明 |
|--------|------|
| No | 行番号（左固定） |
| 保/停 | 保留・停止・リワーク等のフラグ文字列（左固定） |
| 状態 | NowSt |
| TL | タイムリミット（X時間YY分形式） |
| 優 | ロット優先度 |
| ロットID | LotId |
| キャリアID | CarrierId（処理後はToCarrierId） |
| WF枚数 | WfNum |
| チップ数 | ChipQuantity |
| フロー区分 | FlowClass |
| 管理者 | EngEmpName |
| ポート名 | PortName |
| キャリア状態 | CarrierStatName |
| キャリア位置 | CarrierPosition / DestName |
| 開始予定 | DispatchStartTime（M/d HH:mm形式） |
| コメント | LotCommentsFlag（アイコン表示） |
| 代替 | AltNumber |
| 最終更新 | LotLastUpdate |
| リ | ReworkFlag（リ/追） |

#### 基板系(1A0)のみ
| カラム | 説明 |
|--------|------|
| 進捗 | ShipDiffDay |
| GRB | GrbClass |
| WFID | WfId |
| レシピ | RecipeId |
| 大工程 / 小工程 | OpId / StepId |

## 特殊ロジック

- ロット一覧と装置状態を**並列取得**してパフォーマンスを最適化
- タイムリミット表示: 分数を「X時間YY分」形式に変換
- キャリアID表示: 処理後はアンローダキャリアIDを表示
- キャリア位置: 搬送中は搬送先名を表示
- 行スタイル: 保留/停止/ダミー/レシピ制限に応じた背景色

## API通信

| メッセージID | 用途 |
|-------------|------|
| `mas_.mcgrouplist` | 装置グループマスタ取得 |
| `eq__.areacurlist` | 装置一覧取得 |
| `lot_.list____` | ロット一覧取得 |
| `lot_.listald_` | ロット一覧取得（ALDフォールバック） |
| `eq__.state___` | 装置状態取得 |
