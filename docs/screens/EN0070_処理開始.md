# 処理開始 (EN0070)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0070 |
| ルート | `/process-start` |
| ページタイトル | SPIRYTUS - 処理開始 (EN0070) |
| 使用サービス | WorkService |

## 概要

キャリアIDからロットを照合し、装置を選択して処理開始を登録する画面。作業開始(EN0030)と類似のUIだが、ポートIDの入力が追加される。

## 画面構成

### 1. キャリアID入力エリア
- 作業開始(EN0030)と同一仕様

### 2. ロット情報カード
- 作業開始(EN0030)と同一レイアウト

### 3. 装置選択テーブル
- 作業開始(EN0030)と同一仕様（大工程・小工程・D・装置名）

### 4. 追加入力エリア
| 入力項目 | 最大長 | 説明 |
|---------|--------|------|
| ポートID | 20 | ローダポート |
| アンローダポートID | 20 | アンローダポート |
| 作業メモ | 128 | 2行テキスト |

### 5. ボタンエリア
- **確定** / **クリア**

## API通信

| メッセージID | 用途 | MsgVer |
|-------------|------|--------|
| `lot_.curstate` | ロット現在状態取得 | 04.00 |
| `lot_.prcstart` | ロット処理開始 | 07.00 |
