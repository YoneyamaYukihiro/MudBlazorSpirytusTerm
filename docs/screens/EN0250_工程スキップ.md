# EN0250 工程スキップ

## 概要

キャリアIDを入力してロットの現在工程をスキップする画面。スキップ実行前に時間制限・号機記憶制限のチェックを行い、必要に応じて警告を表示する。

VBソース: `VB/0250/CtsfrmxxEN0250.vb`, `VB/0250/CtsbasxxMG0250.vb`

---

## 画面要素

### 入力エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID | 最大6文字。入力後に「検索」またはEnterキーで取得 |
| 社員ID | スキップ実行者。確定時に必須 |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 検索 | `lot_.curstate` CD="1C" でロット取得 → `lot_.chkskipstep` で可否チェック → `lot_.nextsteplist` で次工程取得 |
| 確定 | `lot_.getrestrict` で制限確認 → `lot_.skipstep` でスキップ実行。制限ある場合は2回クリックで確定 |

### ロット情報表示

| 項目 | タグ |
|------|------|
| ロットID | LOT_ID |
| 品種 | PD_ID + PD_NAME |
| 状態 | NOW_ST |
| WF枚数 | WF_NUM |
| ロット管理者 | ENG_EMP_NAME |
| 現在工程 | OP_ID / STEP_ID |

### 現工程一覧グリッド（STEP_LIST）

| 列 | 説明 |
|----|------|
| No | 行番号 |
| 現大工程 | OP_ID |
| 現小工程 | STEP_ID |
| デフォルト | STEP_DIVISION="1" のとき "○" |
| 装置名 | WP_LIST の WP_NAME（カンマ区切り） |

### 次工程一覧グリッド（NEXT_STEP_LIST）

| 列 | 説明 |
|----|------|
| No | 行番号 |
| 次大工程 | NEXT_OP_ID |
| 次小工程 | NEXT_STEP_ID |
| デフォルト | STEP_DIVISION="1" のとき "○" |
| 装置名 | WP_LIST の WP_NAME（カンマ区切り） |

---

## スキップ可否チェック (lot_.chkskipstep)

検索時に自動実行。RESULT の値に応じてインライン警告を表示する。

| RESULT | 意味 | 警告メッセージ |
|--------|------|--------------|
| 0 | 制限なし（OK） | 表示なし |
| 1 | 時間制限あり | "時間制限が設定されています。" |
| 2 | 号機記憶制限あり | "号機記憶制限が設定されています。" |
| 3 | 両方あり | "時間制限・号機記憶制限が設定されています。" |

---

## 確定フロー

1. 確定ボタン押下 → `lot_.getrestrict` で時間制限を確認
2. **制限なし**: そのまま `lot_.skipstep` を実行
3. **制限あり**: 警告メッセージと「（制限確認）確定」ボタンを表示  
   → 再度クリックで `lot_.skipstep` を実行
4. スキップ成功後、フォームをクリアして次の入力待ち

### SEND_RESULT の意味

| 値 | 意味 |
|----|------|
| 空 | 次工程へ |
| 0 | 中間在庫へ |
| 1 | 最終在庫へ |
| 2 | 組立出庫 |

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `lot_.curstate` | 04.00 | ロット現工程情報取得 (CLASS_DIVISION="1C") |
| `lot_.nextsteplist` | 03.01 | 次工程一覧取得 |
| `lot_.chkskipstep` | 03.00 | スキップ可否チェック |
| `lot_.getrestrict` | 01.00 | 時間制限情報取得 |
| `lot_.skipstep` | 02.00 | 工程スキップ実行 |
