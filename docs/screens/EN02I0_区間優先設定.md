# EN02I0 区間優先設定

## 概要

ロットに対して区間（開始工程〜終了工程）の優先度を設定・変更・削除する画面。

VBソース: `VB/02I0/CtsfrmxxEN02I0.vb`, `VB/02I0/CtsbasxxMG02I0.vb`

---

## 画面要素

### 検索エリア

| 検索モード | 説明 |
|-----------|------|
| ロット | ロットIDを入力。10桁未満は末尾に `*` 付加してワイルドカード検索 (`proc.list____`) |
| 装置名 | `mas_.wplist__` CD="02" で取得した全装置から選択。`lot_.list____` CD="26" で検索 |
| 特定工程 | 大工程・小工程を選択。`lot_.oplotlist` CD="27" で検索 |
| 区間優先設定あり | `lot_.secpriority` に LOT_ID="ALL" を渡し、設定済み全ロットを取得 |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 検索 | 選択した条件でロットを検索し区間優先情報を表示する |
| 追加 | 既存の一覧に追加検索する（重複ロットはスキップ） |
| 全ON/全OFF | 全行の「対象」チェックをトグルする |
| 確定 | チェックされた行の区間優先情報を送信する |

### ロット一覧グリッド

| 列 | 説明 |
|----|------|
| No | 行番号 |
| 対象 | 確定対象チェックボックス |
| ロットID | ロットID（読み取り専用） |
| GRB | GRB区分（読み取り専用） |
| 開始大工程 | 区間開始大工程ID（編集可） |
| 開始小工程 | 区間開始小工程ID（編集可） |
| 終了大工程 | 区間終了大工程ID（編集可） |
| 終了小工程 | 区間終了小工程ID（編集可） |
| 区間優先度 | 区間内の優先度値（編集可） |
| 優先度 | ロット優先順位（読み取り専用） |
| 設定ユーザ | 設定者名（読み取り専用） |
| 設定日時 | 設定日時（読み取り専用） |

| 条件 | 色 |
|------|----|
| 保留または停止 | 黄色 (#FFFF99) |

## 区間優先設定の仕組み

1. 検索モードを選択してロットを検索
2. `lot_.secpriority` で現在の区間優先設定情報を取得
3. グリッドで開始大工程・開始小工程・終了大工程・終了小工程・区間優先度を編集
4. 対象チェックをONにした行を「確定」で `lot_.chgsecpriority` に送信
5. `SECTION_PRIORITY` が空の場合はサーバー側で設定削除として処理される

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `proc.list____` | 03.01 | ロットID検索（ワイルドカード） |
| `lot_.list____` | 12.01 | 装置別ロット検索 (CLASS_DIVISION="26") |
| `lot_.oplotlist` | 07.00 | 特定工程ロット検索 (CLASS_DIVISION="27") |
| `lot_.secpriority` | 02.00 | 区間優先設定情報取得 |
| `lot_.chgsecpriority` | 01.00 | 区間優先設定変更 |
| `mas_.wplist__` | 05.01 | 全装置一覧取得 (CLASS_DIVISION="02") |
| `mas_.useoplist` | 02.00 | 大工程マスタ取得 |
| `lot_.steplist` | 03.00 | 小工程一覧取得 |
