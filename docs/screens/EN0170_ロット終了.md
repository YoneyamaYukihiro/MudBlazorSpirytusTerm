# EN0170 ロット終了(ロットアウト)

## 基本情報

| 項目 | 値 |
|------|----|
| 機能ID | EN0170 |
| ルート | `/lot-out` |
| ページタイトル | SPIRYTUS - ロット終了(ロットアウト) (EN0170) |
| 使用サービス | `LotOutService` |

VBソース: `VB/0170/CtsfrmxxEN0170.vb`, `VB/0170/CtsbasxxMG0170.vb`

---

## 概要

キャリアIDを入力してロット情報を取得し、終了区分（不良・保留・払出）を選択してロット終了（ロットアウト）を実行する画面。終了理由コードと終了責任者IDを指定して確定する。

---

## 画面構成

### キャリアID入力エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID | テキストフィールド（最大6文字）。Enterキーまたは「検索」ボタンで検索を実行 |
| 検索ボタン | `lot_.curstate`（MsgVer="04.00", CLASS_DIVISION="1E"）でロット現工程情報を取得 |

### ロット情報表示エリア（検索後に表示）

| 項目 | タグ |
|------|------|
| ロットID | LOT_ID |
| 品種 | PD_ID + PD_NAME |
| 状態 | NOW_ST |
| WF枚数 | WF_NUM |
| ロット担当 | ENG_EMP_NAME |
| 現在工程 | OP_ID / STEP_ID |
| 流動区分 | FLOW_CLASS |

### 終了区分選択エリア（検索後に表示）

ラジオボタンで終了区分を選択する。

| 値 | 表示 | 説明 |
|----|------|------|
| 2 | 不良 (Scrap) | デフォルト選択。VBソース: optScrapHoldTake0 |
| 4 | 保留 (Hold) | VBソース: optScrapHoldTake1 |
| 3 | 払出 (Take) | VBソース: optScrapHoldTake2 |

### 確定エリア（検索後に表示）

| フィールド | 説明 |
|-----------|------|
| 終了理由コード | 理由コードID（VBソース: mstrTaihiEndCode）。任意 |
| 終了責任者ID | 必須。VBソース: txtEmpID。Enterキーで確定も可 |
| 作業メモ | 任意テキスト（複数行）。VBソース: txtWorkMemo |

| ボタン | 説明 |
|--------|------|
| 確定 | `lot_.terminate`（MsgVer="03.01", CLASS_DIVISION="1E"）を呼び出してロット終了を実行 |

---

## 確定フロー

1. キャリアIDを入力してEnterキーまたは「検索」ボタンを押下
2. `lot_.curstate`（CLASS_DIVISION="1E"）でロット現工程情報を取得・表示
3. 終了区分をラジオボタンで選択（デフォルト: 不良=2）
4. 必要に応じて終了理由コードを入力
5. 終了責任者IDを入力（必須）してEnterキーまたは「確定」ボタンを押下
6. `lot_.terminate` を送信  
   送信パラメータ: LOT_ID, CLASS_DIVISION="1E", CLASS（終了区分）, REASON_CODE, RESPONSIBLE_EMP_ID, EMP_ID, COMMENTS, LOT_LAST_UPDATE
7. 成功後：スナックバーに完了メッセージ（例: "ロット終了しました。（不良）"）を表示し、フォームをクリア
8. 失敗時：エラーアラートとスナックバーを表示。MsgCode がある場合は合わせて表示

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `lot_.curstate` | 04.00 | ロット現工程情報取得（CLASS_DIVISION="1E"）（VBソース: pubblnLotCurstate_Sel） |
| `lot_.terminate` | 03.01 | ロット終了実行（VBソース: pubblnLotTerminate_Upd） |
