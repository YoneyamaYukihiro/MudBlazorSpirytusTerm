# EN00H0 対向基板処置登録

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00H0 |
| ルート | `/opposite-substrate-register` |
| ページタイトル | SPIRYTUS - 対向基板処置登録 (EN00H0) |
| 使用サービス | 未実装 (`carr.curstate`、対向基板処置登録メッセージ) |

## 概要

対向基板（CF基板 / TFT基板）のキャリアIDを照合してロット情報を取得し、廃棄・再利用・保管・返却などの処置を登録する画面。キャリアIDは6文字固定でEnterキーまたは「照合」ボタンで照合を実行し、ロット情報取得後に処置コードと処置WF枚数を指定して確定する。

---

## 画面構成

### 対向基板選択エリア

| フィールド | 説明 | 必須 | 制約 |
|-----------|------|:----:|------|
| 基板種別 | CF基板 / TFT基板 から選択 | — | ドロップダウン（デフォルト: CF） |
| キャリアID | 照合対象のキャリアID | ○ | 6文字固定・英大文字自動変換。Enterキーで照合実行 |
| 照合ボタン | キャリアIDが入力済みの場合に有効 | — | `carr.curstate` でロット情報を取得する（未実装） |

### 基板ロット情報（照合後に表示）

| 項目 | タグ |
|------|------|
| ロットID | `_lotId` |
| 機種ID | `_pdId` |
| 基板種別 | `_substrateType` |
| ロット状態 | `_nowSt` |
| WF枚数 | `_wfNum` |

### 処置設定エリア（照合後に表示）

| フィールド | 説明 | 必須 | 制約 |
|-----------|------|:----:|------|
| 処置コード | 廃棄 (01) / 再利用 (02) / 保管 (03) / 返却 (04) から選択 | ○ | ドロップダウン |
| 作業者ID | 処置を実施する作業者のID | — | 最大10文字 |
| 処置WF枚数 | 処置対象のウェーハ枚数 | — | 最大3桁・数値 |
| コメント | 処置に関する補足コメント | — | 最大256文字・複数行 |

### 操作ボタン（照合後に表示）

| ボタン | 有効条件 | 説明 |
|--------|---------|------|
| 処置登録確定 | 処置コードが選択済み、かつ処理中でない | 対向基板処置登録メッセージを送信する（未実装） |
| クリア | 処理中でない | 全フィールドをリセットし、照合後の表示を非表示にする |

---

## 操作フロー

1. 基板種別（CF / TFT）を選択する
2. キャリアID（6文字）を入力し、Enterキーまたは「照合」ボタンを押下する
3. `carr.curstate` でキャリアに紐付くロット情報を取得し、「基板ロット情報」エリアに表示する（未実装）
4. 処置コードを選択し、必要に応じて作業者ID・処置WF枚数・コメントを入力する
5. 「処置登録確定」ボタンを押下する
6. 対向基板処置登録メッセージを送信する（未実装）
7. 登録成功後、スナックバーに完了メッセージを表示し、全フィールドをクリアする
