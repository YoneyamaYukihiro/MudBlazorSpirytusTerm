---

## 概要

装置・装置グループ・ガイダンスレベルなどの条件を指定して、MES が発行したガイダンス情報（異常・警告・情報メッセージ）の一覧を取得・表示する画面。取得区分として「最新 (07)」と「期間指定 (3G)」を切り替えることができる。一覧はガイダンスレベルに応じて色分けされる。本画面は現在実装中であり、メッセージ送信はスタブとなっている。

---

## 画面構成

### 検索条件エリア

| フィールド | 種別 | 最大文字数 | 説明 |
|-----------|------|-----------|------|
| 取得区分 | セレクトボックス | — | `07`（最新）/ `3G`（期間指定）。デフォルト: `07` |
| 開始日 | テキスト | 8 | YYYYMMDD 形式。取得区分が `3G` のときのみ表示 |
| 開始時刻 | テキスト | 6 | HHMMSS 形式。取得区分が `3G` のときのみ表示 |
| 終了日 | テキスト | 8 | YYYYMMDD 形式。取得区分が `3G` のときのみ表示 |
| 終了時刻 | テキスト | 6 | HHMMSS 形式。取得区分が `3G` のときのみ表示 |
| 装置グループID | テキスト | 20 | McGroupId |
| 装置ID | テキスト | 20 | WpId |
| ガイダンスレベルID | テキスト | 4 | GuideLevelId |
| ソート区分 | セレクトボックス | — | `1`（発生日時 昇順）/ `2`（発生日時 降順）。デフォルト: `2` |
| 最新取得 | ボタン (Primary) | — | `guidinfo____` (MsgVer="02.00") でガイダンス情報を取得。取得中はスピナーを表示 |

---

### ガイダンス一覧テーブル（取得成功後に表示）

行のガイダンスレベルが `E` / `ERROR` の場合は行全体をエラーテーマ色で強調表示する。

| 列 | 説明 |
|----|------|
| No. | 行番号 |
| レベル | GuideLevelId。E/W/I に応じてチップの色が変化（下記参照） |
| 発生日時 | Date — ガイダンス発生日時 |
| 装置ID | WpId |
| 装置名 | WpName |
| ポートID | PortId |
| ロットID | LotId |
| キャリアID | CarrierId |
| 大工程 | OpId |
| 小工程 | StepId |
| コード | GuideCode（太字） |
| メッセージ | GuideMsg（折り返し表示、最大幅 300px） |

#### ガイダンスレベル色分け

| レベル値 | チップ色 | 行色 |
|---------|---------|------|
| E / ERROR | Error (赤) | mud-theme-error |
| W / WARNING | Warning (黄) | — |
| I / INFO | Info (青) | — |
| その他 | Default (グレー) | — |

検索後に結果が0件の場合、「ガイダンス情報はありません。」のインフォアラートを表示する。

## 操作フロー

1. 取得区分（最新 / 期間指定）を選択する。
2. 期間指定の場合は開始日・開始時刻・終了日・終了時刻を入力する。
3. 必要に応じて装置グループID・装置ID・ガイダンスレベルID・ソート区分を入力する。
4. **最新取得** ボタンをクリックする。
5. `guidinfo____` (MsgVer="02.00") を送信し、ガイダンス一覧を取得する。
6. 成功時: テーブルにガイダンス情報を表示し、Snackbar に「ガイダンス {件数} 件を取得しました。」を表示する。
7. 結果が0件の場合: 「ガイダンス情報はありません。」のアラートを表示する。
8. 失敗時: エラーメッセージをアラートに表示する。
