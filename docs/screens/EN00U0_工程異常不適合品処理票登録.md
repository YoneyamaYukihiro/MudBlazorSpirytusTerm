# EN00U0 工程異常/不適合品処理票登録

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00U0 |
| ルート | `/abnormal-processing-register` |
| ページタイトル | SPIRYTUS - 工程異常/不適合品処理票登録 (EN00U0) |
| 使用サービス | 未実装 (`lot_.curstate`、工程異常/不適合品処理票登録メッセージ) |

## 概要

工程上で発生した異常または不適合品に対して処理票（工程異常処理票 AB / 不適合品処理票 NC）を作成・登録する画面。キャリアIDを照合して対象ロット情報を取得した後、異常発生工程・装置・原因コード・影響WF枚数・異常内容・処置内容を記録して確定する。

---

## 画面構成

### 処理票種別 + 対象ロット入力エリア

| フィールド | 説明 | 必須 | 制約 |
|-----------|------|:----:|------|
| 処理票種別 | 工程異常処理票 (AB) / 不適合品処理票 (NC) から選択 | — | ドロップダウン（デフォルト: AB） |
| キャリアID | 照合対象のキャリアID | ○ | 6文字固定・英大文字自動変換。Enterキーで照合実行 |
| 照合ボタン | キャリアIDが入力済みの場合に有効 | — | `lot_.curstate` でロット情報を取得する（未実装） |

### 対象ロット情報（照合後に表示）

| 項目 | タグ |
|------|------|
| ロットID | `_lotId` |
| 機種ID | `_pdId` |
| ロット状態 | `_nowSt` |
| 大工程 | `_opId` |
| 小工程 | `_stepId` |
| WF枚数 | `_wfNum` |

### 処理票内容エリア（照合後に表示）

| フィールド | 説明 | 必須 | 制約 |
|-----------|------|:----:|------|
| 異常発生 大工程ID | 異常が発生した大工程のID（照合時に現在工程を初期値として設定） | — | 最大10文字 |
| 異常発生 小工程ID | 異常が発生した小工程のID（照合時に現在工程を初期値として設定） | — | 最大10文字 |
| 異常発生 装置ID | 異常が発生した装置のID | — | 最大20文字 |
| 異常原因コード | 異常原因を識別するコード | — | 最大10文字 |
| 影響WF枚数 | 異常の影響を受けたウェーハ枚数 | — | 最大3桁・数値 |
| 登録者ID | 処理票を登録する作業者のID | — | 最大10文字 |
| 異常内容 | 異常の詳細内容を記述するテキスト | ○ | 最大512文字・複数行 |
| 処置内容 | 異常に対して実施した処置の内容 | — | 最大512文字・複数行 |

### 操作ボタン（照合後に表示）

| ボタン | 有効条件 | 説明 |
|--------|---------|------|
| 処理票登録 | 異常内容が入力済み、かつ処理中でない | 工程異常/不適合品処理票登録メッセージを送信する（未実装） |
| クリア | 処理中でない | 全フィールドをリセットし、照合後の表示を非表示にする |

---

## 操作フロー

1. 処理票種別（AB: 工程異常処理票 / NC: 不適合品処理票）を選択する
2. キャリアID（6文字）を入力し、Enterキーまたは「照合」ボタンを押下する
3. `lot_.curstate` でロット情報を取得し、「対象ロット情報」エリアに表示する（未実装）
   - 異常発生大工程ID・小工程IDには現在工程の値を初期設定する
4. 処理票内容エリアに異常発生工程・装置・原因コード・影響WF枚数・登録者IDを入力する
5. 異常内容（必須）および処置内容を入力する
6. 「処理票登録」ボタンを押下する
7. 工程異常/不適合品処理票登録メッセージを送信する（未実装）
8. 登録成功後、成功アラートおよびスナックバーに "処理票(`<種別>`)を登録しました。 ロット: `<ロットID>`" を表示する
9. 処理票内容フィールドのみクリアし、ロット情報および種別は保持する
