# 工程別ロット一覧 (EN0200)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0200 |
| ルート | `/process-step-lot-list` |
| ページタイトル | SPIRYTUS - 工程別ロット一覧 (EN0200) |
| 使用サービス | ProcessStepLotListService |

## 概要

表示区分（工程別/全工程/テンプレート）を選択し、工程・機種・流動区分でフィルタしてロット一覧を表示する画面。

## 画面構成

### 1. 検索エリア
| 入力項目 | 説明 |
|---------|------|
| 表示区分 | ドロップダウン: 工程別 / 全工程 / テンプレート |
| 大工程 | ドロップダウン（工程別モードのみ有効） |
| 小工程 | ドロップダウン（大工程選択後に有効） |
| 機種 | 複数選択ドロップダウン |
| 種別 | 複数選択ドロップダウン（流動区分） |
| 最新取得ボタン | |

### 2. 表示区分と ClassDivision の対応

| 表示区分 | ClassDivision |
|---------|--------------|
| 工程別 | 27 |
| 全工程 | 02 |
| テンプレート | 3J |

### 3. データグリッド
- 装置別ロット一覧(EN0150)と類似のカラム構成
- 基板系(1A0)は進捗(ShipDiffDay)カラムあり
- 行スタイリング: 保留/停止は黄色、ダミーはオレンジ

## 初期化処理

画面表示時に以下を**並列取得**:
- 大工程マスタ (`mas_.useoplist`)
- 機種マスタ (`mas_.pdlist__`)
- 流動区分マスタ (`mas_.flowlist`)

## API通信

| メッセージID | 用途 |
|-------------|------|
| `mas_.useoplist` | 大工程マスタ取得 |
| `lot_.steplist` | 小工程一覧取得 |
| `mas_.pdlist__` | 機種マスタ取得 |
| `mas_.flowlist` | 流動区分マスタ取得 |
| `lot_.oplotlist` | 工程別ロット一覧取得 |
