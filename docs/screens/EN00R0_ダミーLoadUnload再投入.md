# EN00R0 ダミー Load/Unload/再投入

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00R0 |
| ルート | `/dummy-load-unload` |
| ページタイトル | SPIRYTUS - ダミー Load/Unload/再投入 (EN00R0) |
| 使用サービス | (実装中 — サービスファイル未作成。`carr.curstate`、`dumy.chgcarrier`、`dumy.carstate` を使用予定) |

## 概要

ダミーキャリアのロード・アンロード・再投入操作を行う画面。操作区分（ロード / アンロード / 再投入）をドロップダウンで選択し、キャリアIDを照合してから操作を確定する。確定ボタンのラベルと色は選択した操作区分に応じて動的に変化する。

---

## 画面構成

### 操作モード・キャリアID入力エリア

| フィールド | 説明 |
|-----------|------|
| 操作区分 | ドロップダウン: 「ロード」(LOAD) / 「アンロード」(UNLOAD) / 「再投入」(RETRY) |
| キャリアID | 最大6文字。大文字変換。Enterキーまたは「照合」ボタンで照合 |
| 照合ボタン | キャリア照合を実行。照合中はスピナーを表示 |

### ダミー情報カード（照合後に表示）

| 項目 | 説明 |
|------|------|
| キャリアID | 入力したキャリアID |
| ロットID | 照合で取得したロットID |
| キャリア状態 | キャリアの現在状態名 |

### 装置・工程設定カード（照合後に表示）

| フィールド | 説明 |
|-----------|------|
| 大工程ID | OP_ID。最大10文字 |
| 小工程ID | STEP_ID。最大10文字 |
| 装置ID (WP_ID) | 最大20文字 |
| ポートID | PORT_ID。最大10文字 |
| 作業者ID | EMP_ID。最大10文字 |
| 作業メモ | コメント。最大128文字 |

### 操作ボタン（照合後に表示）

| ボタン | 色 | アイコン | 説明 |
|--------|-----|---------|------|
| ロード確定 | Primary (青) | ArrowDownward | 操作区分=LOADのとき |
| アンロード確定 | Warning (橙) | ArrowUpward | 操作区分=UNLOADのとき |
| 再投入確定 | Success (緑) | Replay | 操作区分=RETRYのとき |
| クリア | Default (白) | Clear | 全フィールドをリセット |

---

## 操作フロー

1. 操作区分をドロップダウンで選択
2. キャリアIDを入力してEnterキーまたは「照合」ボタンを押下
3. `carr.curstate` (または `dumy.chgcarrier` MsgVer="01.01") でキャリア状態を照合 (実装中)
   - 成功時: ダミー情報カードと装置・工程設定カードを表示
4. 大工程ID・小工程ID・装置ID・ポートID・作業者ID・作業メモを必要に応じて入力
5. 「[操作区分] 確定」ボタン押下 → 操作区分に応じたAPI (`dumy.chgcarrier` または `dumy.carstate`) を送信 (実装中)
   - 成功時: スナックバーで完了を通知し画面をクリア

> **注記**: 本画面は現在実装中のスタブ状態。キャリア照合および確定操作のAPIコールはプレースホルダーとなっている。
