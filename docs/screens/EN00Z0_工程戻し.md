# EN00Z0 工程戻し

## 基本情報

| 項目 | 値 |
|------|----|
| 機能ID | EN00Z0 |
| ルート | `/lot-step-back` |
| ページタイトル | SPIRYTUS - 工程戻し (EN02A0) |
| 使用サービス | `LotStepBackService` |

VBソース: `VB/02A0/CtsfrmxxEN02A0.vb`, `VB/02A0/CtsbasxxMG02A0.vb`

---

## 概要

キャリアIDを入力してロット情報と戻し可能な工程一覧を取得し、戻し先の大工程・小工程を選択してイベント履歴一覧を確認した上で工程戻し（イベント履歴削除）を実行する画面。削除不可フラグが含まれる履歴がある場合は確定不可となる。

---

## 画面構成

### キャリアID入力エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID | テキストフィールド（最大6文字）。Enterキーまたは「検索」ボタンで検索を実行 |
| 検索ボタン | `lot_.curstate`（MsgVer="04.00", CLASS_DIVISION="08"）でロット情報を取得し、続けて `mnt_.opsteplist` で戻し可能な工程一覧を取得 |

### ロット情報表示エリア（検索後に表示）

| 項目 | タグ |
|------|------|
| ロットID | LOT_ID |
| 品種 | PD_ID + PD_NAME |
| 状態 | NOW_ST |
| WF枚数 | WF_NUM |
| ロット担当 | ENG_EMP_NAME |
| 現在工程 | OP_ID / STEP_ID |

### 戻し工程選択エリア（検索後に表示）

`mnt_.opsteplist` で取得した戻し可能な大工程・小工程の一覧を表示する。

| フィールド | 説明 |
|-----------|------|
| 戻り大工程 | 戻し可能な大工程 (OP_ID) のドロップダウン。大工程が1件の場合は自動選択 |
| 戻り小工程 | 選択した大工程に紐づく小工程 (STEP_ID) のドロップダウン。小工程が1件の場合は自動選択 |
| 履歴取得ボタン | 大工程・小工程を選択後に有効化。`mnt_.eventhist`（MsgVer="01.00"）でイベント履歴を取得 |

戻し可能な履歴が存在しない場合は「削除可能な履歴が存在しません」警告を表示。

### イベント履歴一覧グリッド（履歴取得後に表示）

削除対象となるイベント履歴を一覧表示。削除不可行が含まれる場合は警告を表示して確定不可とする。

| 列 | タグ | 説明 |
|----|------|------|
| No | — | 行番号（1始まり） |
| 大工程 | OP_ID | 大工程ID |
| 小工程 | STEP_ID | 小工程ID |
| 作業 | EVENT_NAME | ロットイベント名 |
| 日時 | ENTRY_TIME | イベント登録日時 |
| 作業者 | EMP_NAME | 作業者名 |
| 削除可否 | DELETE_PROHIBITED | "1"=不可（赤表示）、それ以外=可（緑表示） |

### 確定エリア（履歴取得後に表示）

| フィールド | 説明 |
|-----------|------|
| 社員ID | 必須。Enterキーで確定も可 |
| 作業メモ | 任意テキスト（複数行）。VBソース: txtWorkMemo |

| ボタン | 説明 |
|--------|------|
| 確定 | `mnt_.delhist_`（MsgVer="01.00"）を呼び出して工程戻し（イベント履歴削除）を実行 |

確定ボタンは以下の条件がすべて満たされた場合に有効化される（`CanConfirm`）:
- ロット情報が取得済み
- イベント履歴一覧が1件以上存在
- 削除不可フラグ（`DELETE_PROHIBITED="1"`）の行が含まれていない
- 社員IDが入力済み

---

## 操作フロー

1. キャリアIDを入力してEnterキーまたは「検索」ボタンを押下
2. `lot_.curstate`（CLASS_DIVISION="08"）でロット情報を取得・表示  
   VBソース: pubblnLotCurstate_Sel
3. `mnt_.opsteplist`（MsgVer="01.00"）で戻し可能な大工程・小工程一覧を取得  
   VBソース: pubblnMntOpStepList_Sel
4. 大工程が1件の場合は自動選択 → 小工程も1件の場合はさらに自動選択し、イベント履歴取得まで自動実行  
   VBソース: cmbRollBackOpID_Validate → prvCmbRollBackStepID_Disp
5. 大工程・小工程を選択して「履歴取得」ボタンを押下
6. `mnt_.eventhist`（MsgVer="01.00"）でイベント履歴一覧を取得・表示  
   VBソース: pubblnMntEventHist_Sel
7. 削除不可行がある場合は警告を表示し、確定を無効化
8. 社員IDを入力してEnterキーまたは「確定」ボタンを押下
9. `mnt_.delhist_` を送信  
   送信パラメータ: LOT_ID, OP_ID, STEP_ID, EMP_ID, COMMENTS, LOT_LAST_UPDATE  
   VBソース: pubblnMntDelHist__Upd
10. 成功後：スナックバーに完了メッセージ（"工程戻しを行ないました。"）を表示し、フォームをクリア
11. 失敗時：エラーアラートとスナックバーを表示。MsgCode がある場合は合わせて表示

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `lot_.curstate` | 04.00 | ロット現工程情報取得（CLASS_DIVISION="08"）（VBソース: CMstrlot_curstateVer） |
| `mnt_.opsteplist` | 01.00 | 戻し可能な大工程/小工程一覧取得（VBソース: pubblnMntOpStepList_Sel） |
| `mnt_.eventhist` | 01.00 | イベント履歴一覧取得（VBソース: pubblnMntEventHist_Sel） |
| `mnt_.delhist_` | 01.00 | 工程戻し実行（イベント履歴削除）（VBソース: pubblnMntDelHist__Upd） |
