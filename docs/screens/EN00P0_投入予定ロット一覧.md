# EN00P0 投入予定ロット一覧

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00P0 |
| ルート | `/lot-throw-rsv-list` |
| ページタイトル | SPIRYTUS - 投入予定ロット一覧 (EN00P0) |
| 使用サービス | 未実装 (`lot_.rsvlist_`) |

## 概要

機種ID・投入予定日範囲・種別区分を条件として投入予定ロットを一覧表示する照会画面。検索結果はテーブル形式で表示し、承認状態をアイコンで、ロット状態をカラーチップで視覚的に区別する。

---

## 画面構成

### 検索条件エリア

| フィールド | 説明 | 制約 |
|-----------|------|------|
| 機種ID | 絞り込む機種ID（空白で全機種対象） | 最大20文字 |
| 投入予定日 From | 投入予定日の開始日を YYYYMMDD 形式で入力 | 最大8文字 例: 20251201 |
| 投入予定日 To | 投入予定日の終了日を YYYYMMDD 形式で入力 | 最大8文字 例: 20251231 |
| 種別区分 | 全種別 / 品確 (QA) / モニター (MN) / ダミー (DM) / 量産 (MQ) から選択 | ドロップダウン（デフォルト: 全種別） |
| 検索ボタン | — | `lot_.rsvlist_` で一覧を取得する（未実装） |

### 検索結果グリッド

| 列 | 説明 |
|----|------|
| No. | 行番号 |
| ロットID | 投入予定ロットのロットID（太字表示） |
| 機種ID | 機種ID |
| 種別 | 種別区分コード |
| WF枚数 | ウェーハ枚数 |
| 投入予定日 | 投入予定日（YYYYMMDD） |
| ロット担当者 | 担当エンジニア名 |
| 状態 | ロットの状態をカラーチップで表示（未承認=Warning / 承認済=Success / 投入済=Info） |
| 承認 | 承認済みの場合はチェックマークアイコン（Success）、未承認の場合は空丸アイコン（Default） |
| 登録日時 | レコード登録日時 |

### 件数表示

検索結果グリッドのツールバーに「全 N 件」を表示する。

### 条件なし / 結果なし時の表示

| 状況 | 表示 |
|------|------|
| 検索前 | グリッドを表示しない |
| 検索実行後・結果0件 | "該当する投入予定ロットがありません。" の Info アラートを表示 |

---

## 操作フロー

1. 検索条件（機種ID・投入予定日範囲・種別区分）を任意に入力する
2. 「検索」ボタンを押下する
3. ローディングインジケーターが表示され、`lot_.rsvlist_` MsgVer="03.00" でデータを取得する（未実装）
4. 取得結果をテーブルに表示する
   - 0件の場合は "該当する投入予定ロットがありません。" を表示する
5. 行をクリックして選択状態にする（選択後の詳細表示・遷移は未実装）
