# 作業終了 (EN0060)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0060 |
| ルート | `/work-end` |
| ページタイトル | SPIRYTUS - 作業終了 (EN0060) |
| 使用サービス | WorkService |

## 概要

キャリアIDからロットを照合し、工程を選択して作業終了を登録する画面。

## 画面構成

### 1. キャリアID入力エリア
- 作業開始(EN0030)と同一仕様

### 2. ロット情報カード（照合後に表示）
- 作業開始(EN0030)と同一レイアウト（ロット情報 + 時間・条件）

### 3. 工程選択テーブル
| カラム | 説明 |
|--------|------|
| 大工程 | OpId |
| 小工程 | StepId |
| D | デフォルト工程は「○」 |

- 装置名は表示しない（作業開始との違い）
- デフォルト工程の自動選択あり

### 4. 追加入力エリア
| 入力項目 | 最大長 |
|---------|--------|
| 作業メモ | 128 |

### 5. ボタンエリア
- **確定**: 工程未選択時は無効
- **クリア**: 全入力をリセット

### 6. ガイダンスメッセージ
- 作業終了成功時にサーバーからガイダンスメッセージが返された場合、画面上部に青色アラートで表示
- メッセージコード付きで表示

## 操作フロー

1. キャリアID入力 → 照合
2. 工程を選択
3. 確定ボタンで作業終了を登録
4. 成功時: Snackbar + ガイダンスメッセージ表示（ある場合）

## API通信

| メッセージID | 用途 | MsgVer |
|-------------|------|--------|
| `lot_.curstate` | ロット現在状態取得 | 04.00 |
| `lot_.wrkend__` | ロット作業終了 | 04.05 |
