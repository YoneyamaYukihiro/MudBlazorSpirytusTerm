# EN00S0 レシピ設定変更

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00S0 |
| ルート | `/recipe-setting-change` |
| ページタイトル | SPIRYTUS - レシピ設定変更 (EN00S0) |
| 使用サービス | 未実装 (`lot_.curstate`、`lot_.userecp_`、レシピ変更メッセージ) |

## 概要

キャリアIDを照合してロットの現在工程・現在レシピIDを取得し、使用可能なレシピ一覧から変更後レシピを選択・入力して変更登録する画面。変更理由の入力が必須であり、誤変更を防止する運用を想定している。

---

## 画面構成

### キャリアID入力エリア

| フィールド | 説明 | 必須 | 制約 |
|-----------|------|:----:|------|
| キャリアID | 照合対象のキャリアID | ○ | 6文字固定・英大文字自動変換。Enterキーで照合実行 |
| 照合ボタン | キャリアIDが入力済みの場合に有効 | — | `lot_.curstate` でロット情報を取得し、`lot_.userecp_` でレシピ一覧を取得する（未実装） |

### ロット情報（照合後に表示）

| 項目 | タグ |
|------|------|
| ロットID | `_lotId` |
| 機種ID | `_pdId` |
| 大工程 | `_opId` |
| 小工程 | `_stepId` |

### レシピ変更設定エリア（照合後に表示）

| フィールド | 説明 | 必須 | 制約 |
|-----------|------|:----:|------|
| 現在のレシピID | 照合時に取得した現在のレシピID | — | 読み取り専用（編集不可） |
| 変更後レシピID | 変更先のレシピIDを直接入力 | ○ | 最大20文字 |
| 作業者ID | 変更操作を実施する作業者のID | — | 最大10文字 |
| 変更理由 | 変更の理由・根拠 | ○ | 最大256文字・複数行 |

### 使用可能レシピ一覧グリッド（照合後に表示）

| 列 | 説明 |
|----|------|
| レシピID | レシピの識別ID（太字表示） |
| レシピ名 | レシピの名称 |
| デフォルト | デフォルトレシピの場合 "○" |
| コメント | レシピの補足説明 |

行を選択することで変更後レシピIDに反映できる想定（未実装）。

### 操作ボタン（照合後に表示）

| ボタン | 有効条件 | 説明 |
|--------|---------|------|
| 変更確定 | 変更後レシピIDが入力済み、かつ処理中でない | レシピ変更メッセージを送信する（未実装） |
| クリア | 処理中でない | 全フィールドをリセットし、照合後の表示を非表示にする |

---

## 操作フロー

1. キャリアID（6文字）を入力し、Enterキーまたは「照合」ボタンを押下する
2. `lot_.curstate` でロット情報（ロットID・機種ID・大工程・小工程・現在レシピID）を取得する（未実装）
3. `lot_.userecp_` で使用可能レシピ一覧を取得してグリッドに表示する（未実装）
4. 一覧からレシピを選択するか、変更後レシピIDフィールドに直接入力する
5. 変更理由を入力し、必要に応じて作業者IDを入力する
6. 「変更確定」ボタンを押下する
7. レシピ変更メッセージを送信する（未実装）
8. 変更成功後、スナックバーに "レシピを `<現在>` → `<変更後>` に変更しました。 ロット: `<ロットID>`" を表示し、全フィールドをクリアする
