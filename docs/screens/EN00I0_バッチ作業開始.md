# バッチ作業開始 (EN00I0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00I0 |
| ルート | `/batch-work-start` |
| ページタイトル | SPIRYTUS - バッチ作業開始 (EN00I0) |
| 使用サービス | BatchService, EquipmentService |

## 概要

装置グループを選択してバッチ一覧を取得し、対象バッチを選択してバッチ作業開始を登録する画面。

## 画面構成

### 1. 装置グループ選択エリア
| 入力項目 | 説明 |
|---------|------|
| 装置グループ | ドロップダウン（初期化時に自動取得、クリア可能） |
| 検索ボタン | バッチ一覧を取得 |

### 2. バッチ一覧（カード形式）
各バッチをカードとして表示。クリックで選択（左端に青いボーダー）。

**カードヘッダー:**
| 表示項目 | 説明 |
|---------|------|
| バッチID | BatchId |
| 装置 | WpName |
| レシピ | RecipeId |
| ロット数 | Lots.Count |
| 装置タイプ | EqType |

**展開時ロット一覧テーブル（選択バッチのみ）:**
| カラム |
|--------|
| ロットID |
| キャリアID |
| フロー区分 |
| 大工程 |
| 小工程 |
| WF枚数 |
| 優先度 |

### 3. 確定エリア（バッチ選択時に表示）
| 入力項目 | 最大長 |
|---------|--------|
| 作業メモ | 128 |

### 4. ボタン
- **確定**: バッチ作業開始を登録
- **クリア**: 選択・入力をリセット

## 操作フロー

1. 装置グループを選択（選択時に自動検索）
2. バッチカードをクリックして選択
3. ロット一覧を確認
4. 作業メモを入力（任意）
5. 確定ボタンで登録

## API通信

| メッセージID | 用途 | ClassDivision |
|-------------|------|---------------|
| `mas_.mcgrouplist` | 装置グループマスタ取得 | - |
| `bat_.lotlist_` | バッチ組ロット情報取得 | 10 (作業開始) |
| `bat_.startwrk` | バッチ作業開始登録 | 3B |
