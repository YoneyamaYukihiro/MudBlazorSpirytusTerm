# EN00T0 装置データ参照/登録

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00T0 |
| ルート | `/equipment-data` |
| ページタイトル | SPIRYTUS - 装置データ参照/登録 (EN00T0) |
| 使用サービス | `EquipmentDataService` |

## 概要

ロットIDと工程を指定して装置収集項目を取得し、収集データの参照および手動入力による登録を行う画面。データ単位はロット単位またはWF単位を選択できる。

VBソース: `VB/00T0/CtsbasxxMG00T0.vb` (pubblnLotCollectParams_Sel)

---

## 画面構成

### 検索条件エリア

| フィールド | 説明 |
|-----------|------|
| ロットID | 必須。最大20文字 |
| 大工程ID | 任意。最大10文字 |
| 小工程ID | 任意。最大10文字 |
| データ単位 | ドロップダウン: 「ロット単位」(1) / 「WF単位」(2) |
| WFID | データ単位=「WF単位」選択時のみ表示。最大10文字 |
| 取得ボタン | `lot_.collectparams` で装置収集項目を取得 |

### 収集データ一覧（取得後に表示）

取得後に以下のサマリ情報を表示する。

| 項目 | 説明 |
|------|------|
| カテゴリID | CATEGORY_ID |
| ロットデータ収集完了フラグ | LOT_DATA_COLL_COMP_FLAG |

収集データが存在する場合、テーブルを表示する。

| 列 | 説明 |
|----|------|
| 項目名 | ITEM_NAME |
| カテゴリID | CATEGORY_ID |
| 収集タイプ | COLLECTION_TYPE |
| CEID | CEID |
| 現在値 | CURRENT_VALUE (参照用) |
| 入力値 | ユーザーが登録値を入力するテキストフィールド |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| データ登録 | 入力した収集データを登録 (`lot_.regcollectparams` 等で登録、実装中) |
| クリア | 全フィールドをリセット |

---

## 操作フロー

1. ロットIDを入力し、必要に応じて大工程ID・小工程ID・データ単位・WFIDを設定
2. 「取得」ボタン押下 → `lot_.collectparams` (MsgVer="01.01") で収集項目を取得
   - 失敗時: エラーアラートを表示
   - 成功時: 収集データ一覧を表示
3. 収集データがある場合、「入力値」列に登録したい値を入力
4. 「データ登録」ボタン押下 → 収集データを登録 (実装中)
   - 成功時: スナックバーで完了を通知

> **注記**: データ登録処理は現在実装中のスタブ状態。
