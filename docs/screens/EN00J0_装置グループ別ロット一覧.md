# 装置グループ別ロット一覧 (EN00J0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00J0 |
| ルート | `/mc-group-lot-list` |
| ページタイトル | SPIRYTUS - 装置グループ別ロット一覧 (EN00J0) |
| 使用サービス | McGroupLotListService, EquipmentService |

## 概要

装置グループを選択し、そのグループに属する全装置のロット一覧を横断的に表示する画面。

## 画面構成

### 1. 検索エリア
| 入力項目 | 説明 |
|---------|------|
| 装置グループ | ドロップダウン（クリア可能、初期化時に自動取得） |
| 検索ボタン | ローディング表示付き |
| 件数表示 | 取得件数 |

### 2. データグリッド（MudDataGrid）
| カラム | ソート | フィルタ |
|--------|-------|---------|
| ロットID | ○ | ○ |
| キャリアID | ○ | ○ |
| 大工程 | ○ | ○ |
| 小工程 | ○ | ○ |
| 状態 | ○ | ○ |
| 現在位置 | ○ | ○ |
| フラグ | × | × |
| WF枚数 | ○ | ○ |
| 優先度 | ○ | ○ |
| 制限時間 | ○ | ○ |
| 警告時間 | ○ | ○ |
| 開始予定 | ○ | ○ |
| 機種 | ○ | ○ |
| 流動区分 | ○ | ○ |
| 送出SB | ○ | ○ |

### フラグカラム表示
| 値 | 表示 |
|----|------|
| LotHoldFlag="1" | 保 |
| LotStopFlag="1" | 停 |
| ReworkFlag="1" | リ |
| ReworkFlag="2" | 追 |
| CfFlag="1" | CF |

### 行スタイル
- 停止または保留: 背景色 #FFF3E0（淡いオレンジ）

## 操作フロー

1. 装置グループを選択
2. 選択変更で自動検索（OnGroupChanged → FetchAsync）
3. 結果をグリッドに表示
4. カラムフィルタ・ソートで絞り込み

## API通信

| メッセージID | 用途 |
|-------------|------|
| `mas_.mcgrouplist` | 装置グループマスタ取得 |
| `lot_.mcalllotlist` | 装置グループ別ロット一覧取得 |
