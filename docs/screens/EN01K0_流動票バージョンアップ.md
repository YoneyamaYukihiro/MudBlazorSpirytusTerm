# 流動票バージョンアップ (EN01K0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN01K0 |
| ルート | `/traveler-version-up` |
| ページタイトル | SPIRYTUS - 流動票バージョンアップ (EN01K0) |
| 使用サービス | LotTravelerVersionUpService, ProcessStepLotListService |

## 概要

ロットの流動票（トラベラー）のバージョンアップ対象を検索し、一括でバージョンアップを実行する画面。

## 画面構成

### 1. 検索条件エリア
- 機種(PdId)選択、流動区分選択（複数選択可）
- ロットID入力（任意）
- 検索ボタン

### 2. 対象ロット一覧（MudDataGrid）
| 主なカラム |
|-----------|
| ロットID、キャリアID |
| 機種、フロー区分 |
| 工程 (OpId / StepId) |
| バージョン、ロット状態 |
| 最終更新日時 |

### 3. アクションボタン
- **バージョンアップ実行**: 選択したロットのバージョンアップ
- **禁止/解除**: バージョンアップ禁止フラグの切り替え

## API通信

| メッセージID | 用途 |
|-------------|------|
| `lot_.chgtrvlist` | バージョンアップ対象一覧取得 |
| `lot_.chgtraveler` | バージョンアップ実行 |
| `lot_.chgtrvprohibit` | バージョンアップ禁止設定 |
| `lot_.chkContEtApc` | 連続ET/APC チェック |
| `mas_.pdlist__` | 機種マスタ取得 |
| `mas_.flowlist` | 流動区分マスタ取得 |
