# バッチ作業終了 (EN00K0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00K0 |
| ルート | `/batch-work-end` |
| ページタイトル | SPIRYTUS - バッチ作業終了 (EN00K0) |
| 使用サービス | BatchService, EquipmentService |

## 概要

装置グループを選択してバッチ一覧を取得し、対象バッチを選択してバッチ作業終了を登録する画面。バッチ作業開始(EN00I0)と同一のUI構成だが、作業終了後にガイダンスメッセージが表示される点が異なる。

## 画面構成

バッチ作業開始(EN00I0)と同一 + ガイダンスメッセージ表示エリア。

### ガイダンスメッセージ
- 作業終了成功時にサーバーから返されたガイダンスメッセージを青色アラートで表示
- メッセージコード付き
- クリア後も保持（keepGuidance=true）

## 操作フロー

バッチ作業開始(EN00I0)と同一。確定時に `BatchWorkEndAsync` を呼び出す。

## API通信

| メッセージID | 用途 | ClassDivision |
|-------------|------|---------------|
| `mas_.mcgrouplist` | 装置グループマスタ取得 | - |
| `bat_.lotlist_` | バッチ組ロット情報取得 | 13 (作業終了) |
| `bat_.endwrk__` | バッチ作業終了登録 | - |

## 他画面との差異

| 項目 | バッチ作業開始 | バッチ作業終了 |
|------|-------------|-------------|
| ガイダンスメッセージ | なし | あり（GuidanceMsg / GuidanceMsgCode） |
| 確定ボタンアイコン | PlayArrow | Stop |
| ClearAll | 全リセット | keepGuidanceオプションあり |
