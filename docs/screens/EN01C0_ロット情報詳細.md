# ロット情報詳細 (EN01C0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN01C0 |
| ルート | `/lot-detail` |
| ページタイトル | SPIRYTUS - ロット情報詳細 (EN01C0) |
| 使用サービス | LotDetailService |

## 概要

キャリアIDまたはロットIDからロットの詳細情報を参照する画面（読み取り専用）。

## 画面構成

### 1. 検索エリア
- 検索モード切替: 「キャリアID」/「ロットID」
- ID入力欄
- 検索ボタン

### 2. ロット詳細情報（検索後に表示）
多数のフィールドをグリッドレイアウトで表示:

| 主な表示項目 |
|-------------|
| ロットID、キャリアID |
| 機種 (PdId)、フロー区分 |
| 現在工程 (OpId / StepId) |
| ロット状態、WF枚数 |
| ロット管理者、優先度 |
| 保留フラグ、送品先SB |
| 分割ロットリスト |

## API通信

| メッセージID | 用途 |
|-------------|------|
| `lot_.detail__` | ロット詳細情報取得 |
