# EN00V0 工程異常/不適合品処理票一覧

## 概要

工程異常処理票および不適合品処理票の一覧を検索・表示する画面。日付範囲・状態フィルタ・起案者ID・担当者IDで絞り込みができる。一覧は帳票種別（工程異常 "異" / 不適合品 "不"）と承認状態（未処置/処置済/承認済）で色分け表示される。デフォルトの検索期間は過去3年間。

VBソース: `VB/00V0/CtsfrmxxEN00V0.vb`, `VB/00V0/CtsbasxxMG00V0.vb`

---

## 画面要素

### 検索エリア

| フィールド | 説明 |
|-----------|------|
| 開始日 | 検索開始日 (yyyy/MM/dd)。デフォルト: 3年前の今日 |
| 終了日 | 検索終了日 (yyyy/MM/dd)。デフォルト: 本日 |
| 状態フィルタ | 全て / 未処置(0) / 処置済(1) / 承認済(2) |

| 担当者ID | 担当者IDによる絞り込み (FIND_TO_EMP_ID) |

### 行背景色

| 条件 | 色 | 説明 |
|------|----|------|
| APPROVAL_FLAG="2" | 青系 (#DDEEFF) | 承認済 |
| ALL_DISPOSAL_FLAG="1" | 緑系 (#EEFFEE) | 処置済 |
| その他 | 白 | 未処置 |

---

## 操作フロー

1. 検索条件（開始日・終了日・状態フィルタ・起案者ID・担当者ID）を設定
2. 「最新取得」ボタンを押下
3. `excp.reportlist` (MSG_VER="02.00", CLASS_DIVISION="02") で一覧を取得
4. 成功時: 取得日時と件数を表示し、一覧をレンダリング
5. 状態フィルタを変更するとクライアント側でリアルタイムに絞り込み表示

### 状態フィルタのロジック

| フィルタ値 | 条件 |
|-----------|------|
| all | 全件表示 |
| 2 (承認済) | APPROVAL_FLAG="2" |
| 1 (処置済) | ALL_DISPOSAL_FLAG="1" かつ APPROVAL_FLAG≠"2" |
| 0 (未処置) | ALL_DISPOSAL_FLAG≠"1" かつ APPROVAL_FLAG≠"2" |

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `excp.reportlist` | 02.00 | 工程異常/不適合品処理票一覧取得 (CLASS_DIVISION="02") |
| `excp.apply___` | 02.00 | 処理票適用（承認）※サービスに実装済み |
| `excp.cancelapply` | 01.00 | 承認取消 ※サービスに実装済み |
| `excp.delete__` | 02.00 | 処理票破棄 ※サービスに実装済み |
