# ロットコメント (EN0140)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0140 |
| ルート | `/lot-comment` |
| ページタイトル | SPIRYTUS - ロットコメント (EN0140) |
| 使用サービス | LotCommentService, WorkService |

## 概要

ロットに付与されたコメントを編集・登録する画面。

## 画面構成

### 1. キャリアID入力エリア
- キャリアID入力（6桁）
- 照合ボタン

### 2. ロット情報カード（照合後、左側）
| 表示項目 |
|---------|
| ロットID |
| 機種 (PdId + PdName) |
| ロット状態 |
| ロット管理者 |
| WF枚数 |

### 3. コメント編集（照合後、右側）
| 入力項目 | 説明 |
|---------|------|
| ロットコメント | 最大4000文字、8行テキストエリア。文字数カウント表示 |

- 照合時に既存コメントが自動セットされる

### 4. ボタンエリア
- **確定**: コメント登録
- **クリア**: 全入力リセット

## API通信

| メッセージID | 用途 | MsgVer |
|-------------|------|--------|
| `lot_.curstate` | ロット現在状態取得（ClassDivision: "3L"） | 04.00 |
| `lot_.chgcomm_` | ロットコメント登録 | 01.00 |
