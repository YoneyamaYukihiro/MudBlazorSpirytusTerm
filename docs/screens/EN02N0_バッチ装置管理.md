# バッチ装置管理 (EN02N0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN02N0 |
| ルート | `/batch-management` |
| ページタイトル | SPIRYTUS - バッチ装置管理 (EN02N0) |
| 使用サービス | BatchManagementService |

## 概要

バッチ処理装置のレシピ構成設定を管理する画面。レシピの編集、待機ロットの確認、構成登録を行う。

## 画面構成

### 1. 装置選択エリア
| 入力項目 | 説明 |
|---------|------|
| 装置グループ | ドロップダウン（ClassDivision "2G" でバッチ用を取得） |
| 装置 | ドロップダウン（グループ選択で読込） |
| 最新取得ボタン | 3データソースを並列取得 |

### 2. バッチ構成方法カード
| 項目 | 説明 |
|------|------|
| 構成方法 | ドロップダウン: 自動(0) / 手動(1) |
| 最終更新者 | EditEmpName |
| 最終更新日時 | EditTime |

### 3. レシピ設定テーブル（編集可能）
| カラム | 編集 | 説明 |
|--------|------|------|
| 順 | × | SeqNum |
| 種別 | × | RecipeType |
| バッチレシピ | ○ | RecipeId（ドロップダウン） |
| 枚数設定(WF≥) | ○ | WfNum（テキスト） |
| 時間設定(H≥) | ○ | TimeNum（ドロップダウンまたはテキスト） |
| 時間設定(WF≥) | ○ | TimeWfNum（テキスト） |
| 最終更新日時 | × | EditTime |
| 最終更新者 | × | EditEmpName |

### 4. 待機ロット一覧テーブル（読み取り専用）
| カラム | 説明 |
|--------|------|
| No | 行番号 |
| 優 | LotPriority |
| ロットID | LotId |
| レシピ | RecipeId |
| 種 | FlowClass |
| WF | WfQuantity |
| 待時間[H] | WaitTimeH |
| キャリアID | CarrierId |
| キャリア位置 | CurrentPositionName |
| 大工程 | OpId |
| 小工程 | StepId |

### 5. ボタンエリア
- **確定**: 編集内容を登録（変更フラグ自動計算）
- **クリア**

## 特殊ロジック

- 3つのデータソース（構成ステータス・レシピ一覧・待機ロット）を**並列取得**
- 編集行は元の値を保持し、確定時に変更フラグ(EditFlag)を自動計算
- RecipeType によって編集可能フィールドが変化
- グループが1つ、装置が1つの場合は自動選択

## API通信

| メッセージID | 用途 |
|-------------|------|
| `mas_.mcgrouplist` | 装置グループマスタ取得（CD=2G） |
| `mas_.wplist__` | 装置一覧取得 |
| `bat_.composestatus` | バッチ構成ステータス取得 |
| `bat_.recipelist` | レシピ一覧取得 |
| `bat_.waitinglotlist` | 待機ロット一覧取得 |
| `bat_.composeregist` | バッチ構成登録 |
