# ロット流動票 (EN01G0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN01G0 |
| ルート | `/lot-travel` |
| ページタイトル | SPIRYTUS - ロット流動票 (EN01G0) |
| 使用サービス | LotDetailListService |

## 概要

ロットの流動履歴（工程毎の開始・終了・装置・レシピ等の詳細リスト）を参照する画面。

## 画面構成

### 1. 検索エリア
- キャリアIDまたはロットIDで検索

### 2. ロット基本情報
| 表示項目 |
|---------|
| ロットID、キャリアID、機種 |
| 現在工程、状態、WF枚数 |
| 現在シーケンス番号 |

### 3. 流動履歴テーブル
| カラム | 説明 |
|--------|------|
| Seq | シーケンス番号 |
| キャリアID | 処理時のキャリア |
| 大工程 / 小工程 | OpId / StepId |
| 開始日時 / 終了日時 | StartTime / EndTime |
| WF枚数 / チップ数 | WfNum / ChipNum |
| 開始者 / 終了者 | StartEmpName / EndEmpName |
| レシピID | RecipeId |
| 装置 | WpName (WpId) |
| コメント | コメントフラグ付き |

## API通信

| メッセージID | 用途 |
|-------------|------|
| `lot_.detaillist` | ロット流動履歴取得 |
| `lot_.eventcomment` | イベントコメント取得 |
| `lot_.userecp_` | 使用レシピ取得 |
