# バッチ処理終了 (EN00N0)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00N0 |
| ルート | `/batch-process-end` |
| ページタイトル | SPIRYTUS - バッチ処理終了 (EN00N0) |
| 使用サービス | BatchService, EquipmentService |

## 概要

装置グループを選択してバッチ一覧を取得し、対象バッチを選択してバッチ処理終了を登録する画面。バッチ作業開始(EN00I0)と同一のUI構成。

## 画面構成

バッチ作業開始(EN00I0)と同一。

## 操作フロー

バッチ作業開始(EN00I0)と同一。確定時に `BatchProcessEndAsync` を呼び出す。

## API通信

| メッセージID | 用途 | ClassDivision |
|-------------|------|---------------|
| `mas_.mcgrouplist` | 装置グループマスタ取得 | - |
| `bat_.lotlist_` | バッチ組ロット情報取得 | 12 (処理終了) |
| `bat_.prcend__` | バッチ処理終了登録 | - |
