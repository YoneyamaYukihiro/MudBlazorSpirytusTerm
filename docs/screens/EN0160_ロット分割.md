# EN0160 ロット分割

## 基本情報

| 項目 | 値 |
|------|----|
| 機能ID | EN0160 |
| ルート | `/lot-divide` |
| ページタイトル | SPIRYTUS - ロット分割 (EN0160) |
| 使用サービス | `LotDivideService` |

VBソース: `VB/0160/CtsbasxxMG0160.vb`

---

## 概要

分割元キャリアIDを照合してロット情報を取得し、スロットマップから分割先に移動するWFを選択してロット分割を実行する画面。分割元・分割先それぞれの GRB 区分と分割先ロットIDを指定して送信する。

---

## 画面構成

### キャリアID入力エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID（分割元） | 最大6文字（大文字変換）。Enterキーまたは「照合」ボタンで照合を実行 |
| 照合ボタン | `carr.curstate`（MsgVer="05.02"）でキャリア状態を取得 |

### 分割元ロット情報カード（照合後に表示）

| 項目 | タグ |
|------|------|
| ロットID | LOT_ID |
| 機種 | PD_ID（PD_NAME） |
| ロット状態 | NOW_ST |
| ロット担当者 | ENG_EMP_NAME |
| WF枚数 | WF_NUM |

### 分割設定カード（照合後に表示）

| フィールド | 説明 |
|-----------|------|
| GRB区分（分割元） | 分割元ロットの GRB 区分（最大4文字） |
| 分割先ロットID | 分割先ロットのID（最大20文字） |
| GRB区分（分割先） | 分割先ロットの GRB 区分（最大4文字） |
| 作業者ID | 作業者の社員ID（最大10文字） |
| コメント | 任意テキスト（最大128文字、複数行） |

### スロットマップ（照合後に表示）

キャリアの WF 枚数（最大25スロット）に応じて行を生成するテーブル。

| 列 | 説明 |
|----|------|
| スロット | スロット番号（ゼロ埋め2桁） |
| WFID | ウェーハID |
| 状態 | WF区分（WF_CLASS） |
| バッチID | BATCH_ID |
| GRB | GRB区分 |
| 分割先へ | チェックボックス（分割先に移動するWFの選択） |

### ガイダンスメッセージ

分割確定後に成功応答の `MSG` と `MSG_CODE` をインラインアラート（Info）で表示。

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 分割確定 | `lot_.divide__`（MsgVer="02.00"）を呼び出してロット分割を実行 |
| クリア | 全入力・表示内容をリセット |

---

## 操作フロー

1. キャリアIDを入力（6文字）してEnterキーまたは「照合」ボタンを押下
2. `carr.curstate` でキャリア状態取得 → 分割元ロット情報カードとスロットマップが表示される
3. 分割設定カードに GRB 区分・分割先ロットID・作業者IDなどを入力
4. スロットマップで分割先に移動する WF のチェックボックスをオンにする
5. 「分割確定」ボタンを押下
6. チェックされた WF を `DIVIDE_WF_MAP_LIST` として `lot_.divide__` に送信
7. 成功後：スナックバー表示、ガイダンスメッセージを表示し、フォームをクリア
