# EN00C0 運用モード変更/装置状態変更

## 基本情報

| 項目 | 値 |
|------|----|
| 機能ID | EN00C0 |
| ルート | `/equipment-mode-change` |
| ページタイトル | SPIRYTUS - 運用モード変更/装置状態変更 (EN00C0) |
| 使用サービス | `EquipmentService`, `EquipmentModeService` |

VBソース: `VB/00C0/CtsbasxxMG00C0.vb`, `VB/00C0/CtsbasxxCM0050.vb`

---

## 概要

装置グループと装置を選択して現在の装置状態を取得し、3つのタブから操作を選択する画面。タブ1で運用モードの変更（通常変更・強制変更）、タブ2で装置状態の変更、タブ3で搬送ポートの有効・無効変更を行う。

---

## 画面構成

### 装置グループ・装置選択エリア

| フィールド | 説明 |
|-----------|------|
| 装置グループ | `mas_.mcgrouplist` から取得したグループ一覧 |
| 装置 | 選択グループに紐づく装置一覧（`eq__.areacurlist` から取得） |
| 装置状態取得ボタン | 選択装置の現在状態を `eq__.state___` で取得 |

### 装置現在状態表示エリア

| 項目 | タグ |
|------|------|
| 装置ID | WP_ID |
| 装置名 | WP_NAME |
| 運用モード | MES_MODE_ID |
| 装置状態 | USE_NAME |
| 稼動状態 | WP_STOP_FLAG（"1"=停止中、それ以外=通常） |
| 処理順 | COLLECT_TYPE_FLAG |

### タブ1: 運用モード変更

| フィールド | 説明 |
|-----------|------|
| 変更後運用モード | M1（マニュアル１）/ S1（セミオート１）/ S2（セミオート２）/ F（フルオート） |

| コメント | 任意テキスト |

| メッセージ | `eq__.wpmsglist` から取得した装置メッセージ一覧（状態変更時に自動更新） |
| 社員ID | 操作者ID（必須） |
| コメント | 任意テキスト |

| ボタン | 説明 |
|--------|------|

## 操作フロー

### 装置状態取得
1. 装置グループを選択 → 装置リストが自動更新される
2. 装置を選択 → メッセージリストが `eq__.wpmsglist` で更新される
3. 「装置状態取得」ボタンクリック → `eq__.state___` で現在状態を取得、ポート一覧も初期化される

### 運用モード変更（タブ1）
1. 変更後運用モードを選択し、社員IDを入力
2. 「確定」または「強制変更」をクリック
3. 成功時：画面上部にスナックバー表示、装置状態を再取得してフォームをクリア
4. 成功時にガイダンスメッセージがある場合は `Info` アラートで表示

### 装置状態変更（タブ2）
1. 変更後装置状態を選択 → メッセージリストが再取得される
2. 必要に応じてメッセージを選択し、社員IDを入力
3. 「確定」をクリック → `eq__.chguse__` で状態変更
4. 成功時：スナックバー表示、装置状態を再取得してフォームをクリア

### 搬送ポート変更（タブ3）
1. 装置状態取得後にポート一覧が表示される
2. 各ポートの搬送サービスを「可能」/「不可能」で設定
3. 社員IDを入力して「確定」をクリック → `eq__.chgtrnstat` でポート状態変更
4. 成功時：スナックバー表示、装置状態を再取得してフォームをクリア

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|

| `eq__.areacurlist` | 02.00 | 装置グループ内装置一覧取得 |
| `eq__.state___` | 03.00 | 装置現在状態取得 |
| `mas_.wpuselist` | 03.00 | 装置状態マスタ取得 |
| `eq__.wpmsglist` | 01.00 | 装置状態メッセージ取得 |
| `eq__.chgmode_` | 06.00 | 運用モード変更 |
| `eq__.emgchgmode` | 06.00 | 運用モード強制変更 |
| `eq__.chguse__` | 05.00 | 装置状態変更 |
| `eq__.chgtrnstat` | 01.00 | 搬送ポート有効・無効変更 |
