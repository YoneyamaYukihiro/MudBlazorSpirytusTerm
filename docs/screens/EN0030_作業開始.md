# 作業開始 (EN0030)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN0030 |
| ルート | `/work-start` |
| ページタイトル | SPIRYTUS - 作業開始 (EN0030) |
| 使用サービス | WorkService |

## 概要

キャリアIDからロットを照合し、装置を選択して作業開始を登録する画面。

## 画面構成

### 1. キャリアID入力エリア
- キャリアID入力欄（6桁、大文字自動変換、モノスペースフォント）
- 照合ボタン
- ロット取得済チップ（照合成功時に表示）
- バリデーション: 6桁でない場合エラー表示

### 2. ロット情報カード（照合後に表示）
左カード:
| 表示項目 | タグ |
|---------|------|
| ロットID | LotId |
| 機種 | PdId (PdName) |
| ロット状態 | NowSt |
| ロット管理者 | EngEmpName |
| フロー区分 | FlowClass |
| WF枚数/チップ数 | WfNum / ChipQuantity |

右カード（時間・条件）:
| 表示項目 | タグ |
|---------|------|
| 開始日時 | StartTime |
| タイムリミット | LimitTime（黄色で強調） |
| 作業条件 | WorkCondition |
| コメント | Comments |

### 3. 装置選択テーブル
| カラム | 説明 |
|--------|------|
| 大工程 | OpId |
| 小工程 | StepId |
| D | デフォルト装置は「○」 |
| 装置名 | WpName |

- クリックで装置を選択
- デフォルト装置（StepDivision="1"）は自動選択
- 工程が1件のみの場合も自動選択

### 4. 追加入力エリア
| 入力項目 | 最大長 | 説明 |
|---------|--------|------|
| アンローダキャリアID | 6 | 空の場合は既存キャリアを使用 |
| CFキャリアID | 6 | CfCarrierIdが存在する場合のみ表示 |
| 作業メモ | 128 | 2行テキスト |

### 5. ボタンエリア
- **確定**: 装置未選択時は無効。作業開始を登録
- **クリア**: 全入力をリセット

## 操作フロー

1. キャリアID（6桁）を入力し、Enterまたは照合ボタンを押下
2. ロット情報と装置一覧が表示される
3. 装置を選択（デフォルトは自動選択）
4. 必要に応じてアンローダキャリアID・作業メモを入力
5. 確定ボタンで作業開始を登録
6. 成功時: Snackbarに成功メッセージ、画面クリア

## API通信

| メッセージID | 用途 | MsgVer |
|-------------|------|--------|
| `lot_.curstate` | ロット現在状態取得 | 04.00 |
| `lot_.wrkstart` | ロット作業開始 | 07.03 |
