# EN00Q0 ロット投入(組立)

## 基本情報

| 項目 | 値 |
|------|-----|
| 機能ID | EN00Q0 |
| ルート | `/lot-throwin-assembly` |
| ページタイトル | SPIRYTUS - ロット投入(組立) (EN00Q0) |
| 使用サービス | (実装中 — サービスファイル未作成。`lot_.curstate` および `lot_.asmthrowin_` を使用予定) |

## 概要

キャリアIDを複数入力してロット一覧を構築し、組立工程へ一括投入する画面。基板投入 (EN0040) と異なり、複数キャリアをリストに積み上げてからまとめて投入確定する。各キャリアの照合には `lot_.curstate` を使用する予定。

---

## 画面構成

### キャリアID追加エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID | 最大6文字。大文字変換。Enterキーまたは「追加」ボタンでロット一覧へ追加 |
| 追加ボタン | キャリア照合後にロット一覧の末尾へ行を追加 |

### 投入ロット一覧テーブル（1件以上追加後に表示）

| 列 | 説明 |
|----|------|
| No. | 行番号 |
| キャリアID | 入力したキャリアID |
| ロットID | 照合で取得したロットID |
| 種別 | フロー区分 (FLOW_CLASS) |
| WF枚数 | WF_NUM |
| チップ枚数 | CHIP_NUM |
| コメント | コメントがある場合は「有」と表示 |
| 送品先 | 送品先のSB名 (SEND_SB_NAME) |
| (削除) | 行を一覧から除去するアイコンボタン |

### 投入設定エリア（1件以上追加後に表示）

| フィールド | 説明 |
|-----------|------|
| 機種ID | 最大20文字 |
| 種別区分 | 最大4文字 |
| エントリID | 最大20文字 |
| 作業者ID | 最大10文字 |
| ロット担当者ID | 最大10文字 |
| 優先度 | 初期値"1"、最大4文字 |
| コメント(作業メモ) | 最大256文字、2行テキストエリア |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 投入確定 | `lot_.asmthrowin_` でロット一覧を一括投入 (実装中) |
| クリア | 全フィールドおよびロット一覧をリセット |

---

## 操作フロー

1. キャリアIDを入力してEnterキーまたは「追加」ボタンを押下
2. `lot_.curstate` でキャリアを照合し、ロット情報を取得してロット一覧に追加 (実装中)
3. 手順1〜2を繰り返して投入対象ロットをリストアップ
4. 投入設定エリアで機種ID・エントリID・作業者ID等を入力
5. 「投入確定」ボタン押下 → `lot_.asmthrowin_` で一括投入実行 (実装中)
   - 成功時: スナックバーで完了を通知し画面をクリア

> **注記**: 本画面は現在実装中のスタブ状態。キャリア照合および投入確定のAPIコールはプレースホルダーとなっている。
