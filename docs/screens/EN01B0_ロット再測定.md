# EN01B0 ロット再測定

## 概要

キャリアIDを入力してロットを再測定状態に変更登録する画面。検索でロット情報を確認後、作業者IDを入力して確定する。登録成功後はロット状態が再測定状態に変更される。登録結果にガイダンスメッセージコードが含まれる場合は警告として表示する。

VBソース: `VB/01B0/CtsfrmxxEN01B0.vb`, `VB/01B0/CtsbasxxMG01B0.vb`, `VB/COMN/CtsbasxxCM0050.vb`

---

## 画面要素

### 入力エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID | 最大6文字。入力後に「検索」またはEnterキーで取得 |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 検索 | `lot_.curstate` (CD="1R") でロット情報取得 |
| 確定 | `lot_.steprestart` でロット再測定を登録。成功後にフォームをクリア |

### ロット情報表示

| 項目 | タグ |
|------|------|
| ロットID | LOT_ID |
| 品種 | PD_ID + PD_NAME |
| 状態 | NOW_ST |
| WF枚数 | WF_NUM |
| ロット管理者 | ENG_EMP_NAME |
| 現在工程 | OP_ID / STEP_ID |

### ガイダンスメッセージ

確定後、応答に MSG_CODE が含まれる場合に警告アラートとして表示される。

| 項目 | 内容 |
|------|------|
| 警告ヘッダ | 「【警告】ガイダンスコード[MSG_CODE]」 |
| 警告本文 | MSG フィールドの内容 |

### 確定エリア

| フィールド | 説明 |
|-----------|------|
| 作業者ID | 再測定実行者。必須入力。Enterキーで確定可能 |

---

## 操作フロー

1. キャリアIDを入力し「検索」ボタン（またはEnterキー）を押下
2. `lot_.curstate` (MSG_VER="04.00", CLASS_DIVISION="1R") でロット情報取得
3. ロット情報（ロットID・品種・状態・WF枚数・ロット管理者・現在工程）が表示される
4. 作業者IDを入力し「確定」ボタンを押下
5. `lot_.steprestart` (MSG_VER="02.00") でロット再測定を登録
6. **成功・ガイダンスなし**: スナックバーに「ロット再測定を登録しました。キャリア[xxx] ロット[xxx]」を表示してフォームをクリア
7. **成功・ガイダンスあり**: 警告スナックバーとガイダンスアラートを表示してフォームをクリア
8. **失敗**: エラーアラートとスナックバーにエラーメッセージを表示

---

## 使用メッセージ

| メッセージID | バージョン | 用途 |
|-------------|-----------|------|
| `lot_.curstate` | 04.00 | ロット現在状態取得 (CLASS_DIVISION="1R") |
| `lot_.steprestart` | 02.00 | ロット再測定登録 |
