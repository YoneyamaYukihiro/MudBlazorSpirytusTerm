# EN0180 WF状態変更登録

## 概要

キャリアIDを入力してWF（ウェハ）の状態区分（良品・不良・払出し・保留）を一括変更登録する画面。検索後にWF一覧が表示され、各WFの区分と不良チップ数・払出チップ数を入力して確定する。

VBソース: `VB/COMN/CtsfrmxxCM0070.vb`, `VB/COMN/CtsbasxxCM0050.vb`, `VB/COMN/CtsbasxxMG0180.vb`

---

## 画面要素

### 入力エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID | 最大6文字。入力後に「検索」またはEnterキーで取得 |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 検索 | `lot_.curstate` (CD="17") でロット情報取得、`lot_.waferlist` (CD="0T") でWFリスト取得、`mas_.scplist_` (CD="17") で不良コード一覧取得を実行 |
| 確定 | `lot_.insprst_` (CD="17") でWF状態変更を登録。成功後にフォームをクリア |

### ロット情報表示

| 項目 | タグ |
|------|------|
| ロットID | LOT_ID |
| 品種 | PD_ID + PD_NAME |
| 状態 | NOW_ST |
| WF枚数 | WF_NUM |
| 現在工程 | OP_ID / STEP_ID |

### 不良/払出コード選択

不良コードが存在する場合のみ表示される。WF区分が不良または払出し以外に変更された場合は不良チップ数・払出チップ数が0にリセットされる。

| フィールド | 説明 |
|-----------|------|
| 不良/払出コード | `mas_.scplist_` から取得したコードのドロップダウン。良品WFには送信されない |

### WF一覧グリッド (WF_LIST)

| 列 | 説明 |
|----|------|
| スロット | スロット位置 (SLOT_POSITION) |
| WF-ID | ウェハID (WF_ID) |
| 現状態 | WF状態名 (WF_STATUS_NAME) |
| 区分変更 | 良品(1) / 不良(2) / 払出し(3) / 保留(4) のドロップダウン |
| 不良ﾁｯﾌﾟ数 | 最大6文字 (CHIP_OUT_QUANTITY) |
| 払出ﾁｯﾌﾟ数 | 最大6文字 (CHIP_FORWARD_QUANTITY) |

### 確定エリア

| フィールド | 説明 |
|-----------|------|
| 作業者ID | 確定実行者。必須入力。Enterキーで確定可能 |
| 責任者ID | 任意入力 (RESPONSIBLE_EMP_ID) |

---

## 確定フロー

1. キャリアIDを入力し「検索」ボタン（またはEnterキー）を押下
2. `lot_.curstate` (MSG_VER="04.00", CLASS_DIVISION="17") でロット情報取得
3. `lot_.waferlist` (MSG_VER="02.05", CLASS_DIVISION="0T") でWFリスト取得（並行実行）
4. `mas_.scplist_` (MSG_VER="03.00", CLASS_DIVISION="17") で不良コード一覧取得
5. WF一覧で各WFの区分・不良チップ数・払出チップ数を設定
6. 作業者IDを入力し「確定」ボタンを押下
7. `lot_.insprst_` (MSG_VER="02.01", CLASS_DIVISION="17") でWF状態変更を登録
8. 成功時: スナックバーに「WF状態変更を登録しました。」を表示してフォームをクリア
9. 失敗時: エラーアラートとスナックバーにエラーメッセージを表示

### CLASS 区分値

| 値 | 意味 |
|----|------|
| 1 | 良品 |
| 2 | 不良 |
| 3 | 払出し |
| 4 | 保留 |

| `lot_.curstate` | 04.00 | ロット現在状態取得 (CLASS_DIVISION="17") |
