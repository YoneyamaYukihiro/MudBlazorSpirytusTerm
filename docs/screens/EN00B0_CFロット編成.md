# EN00B0 CFロット編成

## 概要

CFロットの編成（投入）を登録する画面。キャリアID・作業者ID・投入数・機種ID・画面サイズ・ロット担当者ID・投入装置ID・エントリIDと、最大18スロット分のパレットマップ（パレットID・チップ数・ロットID）を入力して登録する。画面サイズマスタは画面初期化時に自動取得され、1件のみの場合は自動選択される。

VBソース: `VB/00B0/CtsfrmxxEN00B0.vb`, `VB/00B0/CtsbasxxMG00B0.vb`

---

## 画面要素

### 基本情報入力エリア

| フィールド | 説明 |
|-----------|------|
| キャリアID | 投入先キャリアID。必須入力 |
| 作業者ID | 登録実行者。必須入力 |
| 投入数 | 投入数 (NUM) |
| 機種ID | 品種・機種ID (PD_ID) |
| 画面サイズ | `mas_.screenlist` から取得したドロップダウン (SCREEN_SIZE_ID)。1件のみの場合は自動選択。詰数 (CHIP_COUNT) も合わせて表示 |
| ロット担当者ID | ロット担当者 (ENG_EMP_ID) |
| 投入装置ID | 投入装置 (WP_ID) |
| エントリID | エントリID (ENTRY_ID) |

### パレットマップ (PALETTE_MAP_LIST)

スロット数は1〜18の間で変更可能（デフォルト18）。パレットIDが空のスロットは送信対象外。

| 列 | 説明 |
|----|------|
| スロット | スロット番号 (SLOT_POSITION)。1から順に自動付番 |
| パレットID | パレットID (PALETTE_ID) |
| チップ数 | チップ数 (CHIP_COUNT) |
| ロットID | ロットID (LOT_ID) |

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| CFロット編成登録 | `lot_.cfthrowin` でCFロット編成を登録。キャリアIDと作業者IDが入力済みの場合のみ活性 |
| クリア | 全入力フィールドとパレットマップをリセット |

### ガイダンスメッセージ

登録成功時、応答に MSG が含まれる場合はインフォアラートとして表示される。投入ロットID (LOT_ID) も合わせて表示される。

---

## 操作フロー

1. 画面初期化時に `mas_.screenlist` (MSG_VER="02.00", CF_FLAG="1") で画面サイズマスタを自動取得
2. 基本情報（キャリアID・作業者ID等）を入力
3. パレットマップにスロットごとのパレットID・チップ数・ロットIDを入力
4. 「CFロット編成登録」ボタンを押下
5. パレットIDが入力されているスロットのみ PALETTE_MAP_LIST に含めて `lot_.cfthrowin` (MSG_VER="05.00") を送信
6. **成功・ガイダンスなし**: スナックバーに「CFロット編成登録完了」を表示し、「CFロット編成登録が完了しました。」をガイダンスアラートに表示
7. **成功・ガイダンスあり**: 応答の MSG をガイダンスアラートに表示し、投入ロットIDを合わせて表示
8. **失敗**: エラーアラートとスナックバーにエラーメッセージを表示
